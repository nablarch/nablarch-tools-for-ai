# 4.3 JSP（画面表示）

## タグライブラリ宣言

```jsp
<%@ taglib prefix="c" uri="jakarta.tags.core" %>
<%@ taglib prefix="n" uri="http://tis.co.jp/nablarch" %>
```

## 重要ルール

- デフォルトでHTMLエスケープ（XSS対策）
- `nablarch_`プレフィックスは使用禁止
- name属性: リクエストスコープ変数名.プロパティ名
- 検索順序: Page→Request→RequestParam→Session

## フォーム

```jsp
<!-- 基本 -->
<n:form>内容</n:form>

<!-- 属性: method(POST/GET) action name useToken(CSRF) enctype(multipart/form-data) -->
<n:form method="POST" useToken="true">...</n:form>
```

## 入力項目

### テキスト系
```jsp
<!-- n:text 必須:name 主要:cssClass errorCss maxlength placeholder disabled readonly -->
<n:text name="form.clientName" cssClass="form-control" errorCss="input-error" maxlength="64" />

<!-- n:password 必須:name 主要:cssClass errorCss maxlength placeholder disabled readonly -->
<n:password name="form.password" cssClass="form-control" />

<!-- n:textarea 必須:name rows cols 主要:cssClass errorCss -->
<n:textarea name="form.note" rows="5" cssClass="form-control" />
```

### バリデーションエラー時の値復元

#### デフォルト動作（copyBeanToRequestScopeOnError=false）
- `@InjectForm`は入力値をFormにマッピング後、バリデーション実行
- **バリデーション成功時のみ**Formがリクエストスコープに設定される
- **バリデーションエラー時は、Formはリクエストスコープに設定されない**
- JSPの入力項目タグ（`n:text`, `n:select`等）は以下の順序で値を検索:
  1. Page スコープ
  2. Request スコープ
  3. **Request パラメータ** ← エラー時はここから値を取得
  4. Session スコープ
- エラー時もユーザーが入力した値は**リクエストパラメータから自動復元**され、再入力不要

#### copyBeanToRequestScopeOnError=trueの場合
- バリデーションエラー時も、入力値がマッピングされたFormをリクエストスコープに設定
- JSTL(EL式)などでリクエストスコープ経由で値を参照したい場合に使用
- 設定方法は公式ドキュメントの「バリデーションエラー時にもリクエストパラメータをリクエストスコープから取得したい」を参照

**重要:** バリデーションエラーになるような値（数値項目に文字列入力等）でもマッピングできるよう、**FormのプロパティはすべてString型で定義**する必要がある。

### 選択項目
```jsp
<!-- n:select 必須:name listName elementValueProperty elementLabelProperty 主要:withNoneOption cssClass errorCss -->
<n:select name="form.industryCode" listName="industries" 
    elementValueProperty="code" elementLabelProperty="name" 
    withNoneOption="true" cssClass="form-select" />

<!-- n:radioButtons 必須:name listName elementValueProperty elementLabelProperty -->
<n:radioButtons name="form.type" listName="types" 
    elementValueProperty="value" elementLabelProperty="label" />

<!-- n:radioButton 必須:name value label 主要:cssClass -->
<n:radioButton name="form.type" value="1" label="開発" />

<!-- n:checkboxes 必須:name listName elementValueProperty elementLabelProperty -->
<n:checkboxes name="form.classes" listName="classes" 
    elementValueProperty="value" elementLabelProperty="label" />

<!-- n:checkbox 必須:name 主要:value offValue label cssClass -->
<n:checkbox name="form.agreement" value="1" offValue="0" label="同意" />

<!-- n:hidden 必須:name -->
<n:hidden name="form.projectId" />

<!-- n:file 必須:name 主要:cssClass accept multiple -->
<n:file name="form.file" accept=".pdf" multiple="true" />
```

## ボタン・リンク

```jsp
<!-- n:button 必須:uri 主要:name cssClass disabled allowDoubleSubmission -->
<n:button uri="/action/confirm" cssClass="btn btn-success">登録</n:button>

<!-- n:submit 必須:uri type 主要:value cssClass -->
<n:submit uri="/action/create" value="登録" />

<!-- n:a 主要:href cssClass target -->
<n:a href="/action/list">一覧</n:a>

<!-- パラメータ追加: n:param 必須:paramName name/value(どちらか) -->
<n:button uri="/action/show">
    <n:param paramName="id" name="row.id" />
    詳細
</n:button>
```

## 値の表示

```jsp
<!-- n:write 必須:name 主要:withHtmlFormat -->
<n:write name="project.name" />
<n:write name="project.note" withHtmlFormat="true" />

<!-- 関数 -->
${n:br(text)}
${n:formatDate(date, 'yyyy/MM/dd')}
${n:format('currency', amount)}

<!-- n:code 必須:codeId name -->
<n:code codeId="PROJECT_TYPE" name="project.type" />

<!-- n:codeSelect 必須:codeId name 主要:withNoneOption -->
<!-- n:codeRadioButtons/n:codeCheckboxes 必須:codeId name -->
<n:codeSelect codeId="PROJECT_TYPE" name="form.type" withNoneOption="true" />
```

### 値のフォーマット仕様

#### EL式での関数フォーマット
```jsp
<!-- 日付フォーマット関数 -->
${n:formatDate(project.startDate, 'yyyy/MM/dd')}
${n:formatDate(project.createdAt, 'yyyy年MM月dd日 HH:mm:ss')}

<!-- 数値フォーマット関数 -->
${n:format('number', project.amount, '#,###')}

<!-- 改行変換（\nを<br>タグに変換） -->
${n:br(project.note)}
```

## 確認画面パターン

```jsp
<!-- 入力画面(create.jsp) -->
<n:form>
    <n:text name="form.name" />
    <n:forInputPage>
        <n:button uri="/action/confirm">確認</n:button>
    </n:forInputPage>
    <n:forConfirmationPage>
        <n:button uri="/action/back">戻る</n:button>
        <n:button uri="/action/create" allowDoubleSubmission="false">確定</n:button>
    </n:forConfirmationPage>
</n:form>

<!-- 確認画面(confirm.jsp) -->
<n:confirmationPage path="./create.jsp" />

<!-- 非表示項目 -->
<n:ignoreConfirmation>...</n:ignoreConfirmation>
```

### 確認画面での自動ラベル表示
入力項目タグ（`n:text`, `n:textarea`, `n:password`等）は確認画面で**自動的にラベル表示**に切り替わる。
`n:forConfirmationPage`タグは不要。

```jsp
<!-- 入力画面(create.jsp) -->
<n:text name="form.name" />
<!-- → 入力画面: <input type="text" ...> -->
<!-- → 確認画面: <span>値</span> (自動ラベル化) -->

<!-- 選択項目も同様 -->
<n:select name="form.industryCode" listName="industries" 
    elementValueProperty="code" elementLabelProperty="name" />
<!-- → 入力画面: <select>...</select> -->
<!-- → 確認画面: <span>選択したラベル</span> (自動ラベル化) -->
```

内部的には`SinglevaluedInputTagWriterSupport.writeTag()`が`TagUtil.isConfirmationPage()`で判定し、
確認画面の場合は`createOutputTag()`（ラベル表示）、入力画面の場合は`createInputTag()`（入力フィールド）を呼び出す。

## GETメソッド使用時の制約

## コード入力部品のラベルパターン

コード入力部品（`n:codeSelect`, `n:codeRadioButtons`, `n:codeCheckboxes`など）では、`labelPattern`属性を使用してラベルの表示形式を指定できます。

### `labelPattern`の指定方法

- `labelPattern`属性を使用して、コード値のラベルを整形するパターンを指定します。
- 使用可能なプレースホルダ:
  - `$NAME$` : コード値に対応するコード名称（デフォルト）
  - `$SHORTNAME$` : コード値に対応するコードの略称
  - `$OPTIONALNAME$` : コード値に対応するコードのオプション名称
  - `$VALUE$` : コード値
- `$OPTIONALNAME$` を使用する場合は、`optionColumnName`属性の指定が必須です。
- デフォルト値は `$NAME$` です。

### 使用例

#### `n:codeSelect`タグ
```jsp
<n:codeSelect name="form.type" codeId="PROJECT_TYPE" 
    labelPattern="$NAME$ ($VALUE$)" />
```
- 上記例では、ラベルが「コード名称 (コード値)」の形式で表示されます。

#### `n:codeRadioButtons`タグ
```jsp
<n:codeRadioButtons name="form.status" codeId="STATUS" 
    labelPattern="$SHORTNAME$ - $NAME$" />
```
- 上記例では、ラベルが「略称 - コード名称」の形式で表示されます。

#### `n:codeCheckboxes`タグ
```jsp
<n:codeCheckboxes name="form.options" codeId="OPTIONS" 
    labelPattern="$NAME$ [$OPTIONALNAME$]" 
    optionColumnName="optionalName" />
```
- 上記例では、ラベルが「コード名称 [オプション名称]」の形式で表示されます。
- `optionColumnName="optionalName"` を指定することで、`$OPTIONALNAME$` を使用可能にしています。

これらの設定により、コード入力部品のラベル表示を柔軟にカスタマイズできます。
