# 3.8 @ValidateDataアノテーション

```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
@Interceptor(ValidateData.ValidateDataImpl.class)
@Published
public @interface ValidateData {

    @SuppressWarnings("PublicInnerClass")
    class ValidateDataImpl extends Interceptor.Impl<Object, Result, ValidateData> {
        private static final Logger LOGGER = LoggerManager.get(ValidateData.class);

        @Override
        public Result handle(Object data, ExecutionContext context) {
            final Validator validator = ValidatorUtil.getValidator();
            final Set<ConstraintViolation<Object>> constraintViolations = validator.validate(data);

            if (constraintViolations.isEmpty()) {
                return getOriginalHandler().handle(data, context);
            }

            constraintViolations.stream()
                                .map(violation -> {
                                    Long lineNumber = null;
                                    try {
                                        lineNumber = (Long) BeanUtil.getProperty(data, "lineNumber");
                                    } catch (BeansException e) {
                                        // NOP
                                    }

                                    Message message = MessageUtil.createMessage(
                                            MessageLevel.WARN,
                                            "invalid_data_record",
                                            violation.getPropertyPath().toString(),
                                            violation.getMessage(),
                                            lineNumber);
                                    return message.formatMessage();
                                })
                                .forEach(LOGGER::logWarn);
            return null;
        }
    }
}
```

## 使用方法

### FormクラスでlineNumberプロパティ定義
```java
@Csv(properties = {"id", "name", "amount"}, type = CsvType.CUSTOM)
public class ImportForm {
    @Domain("userId") private String id;
    @Domain("userName") private String name;
    @Domain("amount") private String amount;
    private Long lineNumber; // バリデーションエラー時の行番号出力用（必須）
    // getter/setter

    @LineNumber // getterに付与することで、 対象データが何行目のデータであるかを自動的に設定できる。
    public Long getLineNumber() {
        return lineNumber;
    }
}
```

### BatchActionでの使用
```java
@ValidateData
public Result handle(ImportForm inputData, ExecutionContext context) {
    // inputDataはバリデーション済み
    processValidatedData(inputData);
    return new Success();
}
```

### 必須設定（messages.properties）
```properties
invalid_data_record=バリデーションエラー：項目={0}, エラー内容={1}, 行番号={2}
```

## 動作仕様

- **成功時**: 後続handleメソッド実行
- **エラー時**: WARNログ出力、処理停止（nullが返される）
- **ログ例**: バリデーションエラー：項目=id, エラー内容=必須項目です, 行番号=15
