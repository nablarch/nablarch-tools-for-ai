## フォーマット設定

```java
// CSV
@Csv(properties = {"id", "name"}, type = CsvType.CUSTOM)
@CsvFormat(charset = "UTF-8", fieldSeparator = ',')
public class CsvForm {
    private String id;
    private String name;
}

// 固定長  
@FixedLength(length = 30, charset = "UTF-8")
public class FixedForm {
    @Field(offset = 1, length = 10)
    private String id;
}
```
