# 1.5 データバインド

**機能**: CSV/TSV/固定長ファイル ⇔ Java Beans/Map変換  
**制約**: 全プロパティString型、ObjectMapperスレッドアンセーフ  

## 基本的なデータバインドパターン

**読み込み**:
```java
// Java Beans
try (ObjectMapper<Person> mapper = ObjectMapperFactory.create(Person.class, inputStream)) {
    while ((person = mapper.read()) != null) {
        ValidatorUtil.validate(person);
    }
} catch (InvalidDataFormatException e) { }

// Map
DataBindConfig config = CsvDataBindConfig.DEFAULT.withProperties("age", "name");
try (ObjectMapper<Map> mapper = ObjectMapperFactory.create(Map.class, inputStream, config)) {
    while ((data = mapper.read()) != null) { }
}
```

**書き込み**:
```java
try (ObjectMapper<Person> mapper = ObjectMapperFactory.create(Person.class, outputStream)) {
    for (Person p : list) mapper.write(p);
}
```

## フォーマット指定

**CSV(アノテーション)**:
```java
@Csv(type = Csv.CsvType.DEFAULT, properties = {"age", "name"}, headers = {"年齢", "氏名"})
public class Person { private Integer age; private String name; }

// カスタム（全フォーマット項目必須）
@Csv(type = Csv.CsvType.CUSTOM, properties = {"age", "name"}) // Csv.CsvType.CUSTOM指定時は@CsvFormat必須
@CsvFormat(
        fieldSeparator = '\t',
        lineSeparator = "\r\n",
        quote = '\'',
        ignoreEmptyLine = false,
        requiredHeader = false,
        charset = "UTF-8",
        quoteMode = CsvDataBindConfig.QuoteMode.ALL,
        emptyToNull = true)
public class Person { private Integer age; private String name; }
```

**固定長(アノテーション)**:
```java
@FixedLength(length = 19, charset = "MS932")
public class Person {
    @Field(offset = 1, length = 3) @Lpad private Integer age;
    @Field(offset = 4, length = 16) @Rpad private String name;
}
```

**DataBindConfig**:
```java
// CSV
DataBindConfig config = CsvDataBindConfig.DEFAULT.withProperties("age", "name");

// 固定長
DataBindConfig config = FixedLengthDataBindConfigBuilder.newBuilder()
    .length(19).singleLayout()
    .field("age", 1, 3, new Lpad.Converter('0')).build();
```

## ファイルパス管理連携

```java
// FilePathSettingと組み合わせた使用例
FilePathSetting filePathSetting = FilePathSetting.getInstance();
File inputFile = filePathSetting.getFileWithoutCreate("csv-input", "data");

try (ObjectMapper<Person> mapper = ObjectMapperFactory.create(Person.class, new FileInputStream(inputFile))) {
    Person person;
    while ((person = mapper.read()) != null) {
        // 処理
    }
}
```

## CSVフォーマットセット

| 種類 | 列区切り | 行区切り | 囲み文字 | 空行無視 | ヘッダ行 | 文字コード | クォートモード |
|------|----------|----------|----------|----------|----------|------------|----------------|
| DEFAULT | , | \r\n | " | true | true | UTF-8 | NORMAL |
| RFC4180 | , | \r\n | " | false | false | UTF-8 | NORMAL |
| EXCEL | , | \r\n | " | false | false | UTF-8 | NORMAL |
| TSV | \t | \r\n | " | false | false | UTF-8 | NORMAL |

**クォートモード**:
- **NORMAL**: フィールド囲み文字、列区切り文字、改行のいずれかを含むフィールドのみ囲む
- **ALL**: 全てのフィールドを囲む

## マルチレイアウト

**Java Beans**: MultiLayout継承 + RecordIdentifier実装  
**Map**: FixedLengthDataBindConfigBuilder.multiLayout() + recordIdentifier()

## ObjectMapperIterator活用パターン

ObjectMapperにはhasNextメソッドがないため、イテレータを作成することで実装が簡単になる：

```java
public class ObjectMapperIterator<E> implements Iterator<E> {
    private final ObjectMapper<E> mapper;
    private E form;

    public ObjectMapperIterator(ObjectMapper<E> mapper) {
        this.mapper = mapper;
        this.form = mapper.read(); // 初回読み込み
    }

    @Override
    public boolean hasNext() {
        return (form != null);
    }

    @Override
    public E next() {
        final E current = form;
        form = mapper.read(); // 次の行を読み込み
        return current;
    }

    public void close() {
        mapper.close();
    }
}
```

## 注意事項

- **リソース管理**: try-with-resources必須（ObjectMapperはAutoCloseable実装）
- **スレッドセーフ**: ObjectMapperはスレッドアンセーフ、使い回し禁止
- **例外**: InvalidDataFormatException, ApplicationException  
- **大量データ**: ストリーミング処理でメモリ効率化
- **バリデーション**: 読み込み後はValidatorUtil.validate()でチェック
