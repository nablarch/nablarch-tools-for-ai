# 4.3.1 JSP高度な機能

## ポップアップ

```jsp
<!-- n:popupButton 必須:uri 主要:popupWindowName popupOption -->
<n:popupButton uri="/action/search/address" 
    popupWindowName="addressSearch" 
    popupOption="width=600,height=400">住所検索</n:popupButton>

<!-- n:popupLink -->
<n:popupLink uri="/action/help" popupWindowName="help">ヘルプ</n:popupLink>

<!-- パラメータ名変更: n:changeParamName 必須:inputName paramName -->
<n:popupButton uri="/action/search">
    <n:changeParamName inputName="form.keyword" paramName="searchKeyword" />
    検索
</n:popupButton>
```

## ダウンロード

```jsp
<!-- n:downloadButton/n:downloadLink 必須:uri -->
<n:downloadButton uri="/action/report/download">レポートDL</n:downloadButton>

<!-- Actionクラス側 -->
// HttpResponse.download(filename, inputStream)
// StreamResponse.write(filename, outputStream -> {...})
```

```jsp
    <n:compositeKeyRadioButton name="form.selectedKeys" 
        keyNames="projectId,lineNo"

<!-- n:compositeKeyCheckbox 同上 -->
```

## サブミット時JavaScript処理追加

```jsp
<!-- onclick属性で独自処理追加 -->
<n:button uri="/action/delete" 
    onclick="return confirmDelete(event);">削除</n:button>

<script>
function confirmDelete(event) {
    if (!confirm('削除しますか？')) {
        event.preventDefault();
        return false;
    }
    // カスタムタグのJavaScript関数を呼び出す
    return nablarch_submit(event, this);
}
</script>
```

## 表示制御（認可・サービス提供可否）

```jsp
<!-- displayMethod: NODISPLAY(非表示) DISABLED(非活性) NORMAL(通常表示) -->
<n:button uri="/action/admin/delete" 
    displayMethod="NODISPLAY">削除</n:button>
```

```jsp

    listName="categories" 
    elementValueProperty="code" 
    elementLabelProperty="name" 
    onchange="document.getElementById('searchBtn').click();" />
<n:button uri="/action/search" name="searchBtn">検索</n:button>
```

## URI指定方法

```jsp
<!-- 相対パス -->
<n:button uri="./confirm">確認</n:button>

<!-- 絶対パス -->
<n:button uri="/action/client/confirm">確認</n:button>

<!-- https/http強制 -->
<n:a href="https://example.com/secure">セキュア</n:a>

<!-- EL式埋め込み -->
<n:a href="/action/show/${id}">詳細</n:a>
```


## Content Security Policy詳細

```jsp
<!-- セキュアハンドラでnonce生成設定が必要 -->
<n:form>
    <!-- JavaScriptがscript要素にまとまりnonce属性付与 -->
</n:form>

<!-- 任意の要素にnonce埋め込み -->
<script nonce="<n:cspNonce />">
    console.log('init');
</script>

<!-- イベントハンドラでJavaScript処理追加 -->
<button type="button" id="deleteBtn" data-url="/action/delete">削除</button>
<script nonce="<n:cspNonce />">
document.getElementById('deleteBtn').addEventListener('click', function() {
    const url = this.getAttribute('data-url');
    if (confirm('削除しますか？')) {
        location.href = url;
    }
});
</script>
```

## その他の入力項目タグ

```jsp
<!-- HTML5 input要素 -->
<!-- n:email 必須:name -->
<n:email name="form.email" />

<!-- n:tel 必須:name -->
<n:tel name="form.tel" />

<!-- n:url 必須:name -->
<n:url name="form.websiteUrl" />

<!-- n:date 必須:name -->
<n:date name="form.birthday" />

<!-- n:time 必須:name -->
<n:time name="form.appointmentTime" />

<!-- n:number 必須:name 主要:min max step -->
<n:number name="form.age" min="0" max="150" />

<!-- n:range 必須:name 主要:min max step -->
<n:range name="form.volume" min="0" max="100" step="1" />

<!-- n:color 必須:name -->
<n:color name="form.themeColor" />

<!-- n:search 必須:name -->
<n:search name="form.searchKeyword" />
```

## HTMLエスケープなし表示の詳細

```jsp
<!-- n:prettyPrint: 改行→<br>、連続空白→&nbsp; -->
<n:prettyPrint name="formattedMessage" />

<!-- n:rawWrite: 完全にそのまま出力 -->
<n:rawWrite name="richTextHtml" />
```

**警告**: XSS脆弱性のリスクがあるため、信頼できるデータのみに使用

## フォーマッタ拡張

```java
// ValueFormatterインタフェース実装
public class CustomFormatter implements ValueFormatter {
    @Override
    public String format(Object value, String pattern, Object... args) {
        // カスタムフォーマット処理
    }
}
```

```xml
<!-- コンポーネント定義 -->
<component name="valueFormatters" class="java.util.HashMap">
    <map>
        <entry key="custom" value="com.example.CustomFormatter" />
    </map>
</component>
```

```jsp
<!-- 使用 -->
<n:write name="value" valueFormat="custom{pattern}" />
```
