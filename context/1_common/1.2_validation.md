# 1.2 入力値検証 (Bean Validation)

## ドメインバリデーション

### ドメインBean定義
```java
public class SampleDomainBean {
    @Length(max = 50)
    @SystemChar(charsetDef = "全角文字")
    String name;
    
    @Length(min = 8, max = 8)
    @SystemChar(charsetDef = "半角数字")
    String date;
    
    @NumberRange(min = 0, max = 999)
    Integer code;
}
```

### Form使用
```java
public class UserForm {
    @Domain("name")
    @Required  // 必須は個別に設定
    private String userName;
    
    @Domain("date") 
    private String birthday;
    
    @Domain("code")
    private String userCode;
}
```

> **重要：**  
> - Formクラスのプロパティは全て`String`型で定義すること
> - `@Required`はドメインではなく個別のFormに設定する

### 主要なNablarchバリデーションアノテーション
- `@Required`: 必須入力
- `@Length(min=?, max=?)`: 文字列長
- `@SystemChar(charsetDef="文字種名")`: 文字種バリデーション
- `@Domain("ドメイン名")`: ドメインバリデーション
- `@NumberRange(min=?, max=?)`: 数値範囲（整数）
- `@DecimalRange(min="?", max="?")`: 数値範囲（小数）

## 文字種バリデーション

```xml
<!-- 半角数字 -->
<component name="半角数字" class="nablarch.core.validation.validator.unicode.LiteralCharsetDef">
    <property name="allowedCharacters" value="0123456789" />
    <property name="messageId" value="numberString.message" />
</component>

<!-- 全角文字（範囲指定） -->
<component name="全角文字" class="nablarch.core.validation.validator.unicode.RangedCharsetDef">
    <property name="startCodePoint" value="U+3040" />
    <property name="endCodePoint" value="U+309F" />
    <property name="messageId" value="zenkaku.message" />
</component>

<!-- 複合文字種 -->
<component name="英数字" class="nablarch.core.validation.validator.unicode.CompositeCharsetDef">
    <property name="charsetDefList">
        <list>
            <component-ref name="半角数字" />
            <component class="nablarch.core.validation.validator.unicode.LiteralCharsetDef">
                <property name="allowedCharacters" value="abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ" />
            </component>
        </list>
    </property>
    <property name="messageId" value="alphaNumeric.message" />
</component>
```

## 相関バリデーション

```java
public class UserForm {
    private String password;
    private String confirmPassword;
    
    @AssertTrue(message = "{passwordMatch}")
    public boolean isPasswordMatch() {
        if (StringUtil.isNullOrEmpty(password) || StringUtil.isNullOrEmpty(confirmPassword)) {
            return true; // 単項目バリデーションに委ねる
        }
        return Objects.equals(password, confirmPassword);
    }
}
```


### 項目名付きメッセージの設定
```xml
<component name="constraintViolationConverterFactory"
    class="nablarch.core.validation.ee.ItemNamedConstraintViolationConverterFactory" />
```

結果: `[ユーザー名]入力してください。`

## Web/RESTアプリケーション設定

### Webアプリケーション
```xml
<component name="validationStrategy" 
    class="nablarch.common.web.validator.BeanValidationStrategy">
    <!-- バリデーションエラー時もリクエストスコープに値をコピー -->
    <property name="copyBeanToRequestScopeOnError" value="true"/>
</component>
```

### エラーハンドリング
```java
@OnError(type = ApplicationException.class, path = "/WEB-INF/view/user/create.jsp")
public HttpResponse create(HttpRequest request, ExecutionContext context) {
    try {
        UserForm form = ProjectValidatorUtil.validate(UserForm.class, request);
        // 業務処理
    } catch (ApplicationException e) {
        // バリデーションエラー時の追加処理
        throw e;
    }
}
```

## 注意事項

### 必須事項
- **プロパティは全て`String`型**: 型変換エラーを防ぐため
- **必須バリデーション**: `@Required`はドメインではなく個別設定
- **相関バリデーション**: null/空文字の考慮が必要

### データベース相関バリデーション

> **重要：**  
> バリデーション後に業務アクションで実装する（SQLインジェクション対策）

### バリデーショングループ
```java
public class SampleForm {

    @SystemChar(charsetDef = "数字", groups = {Default.class, Test1.class})
    String id;

    @SystemChar.List({
            @SystemChar(charsetDef = "全角文字") // グループを指定しない場合は、 Defaultグループに所属していると見なされる
            @SystemChar(charsetDef = "半角英数", groups = Test1.class),
    })
    String name;

    public interface Test1 {}
}
```
実行
```java
SampleForm form = new SampleForm();

...

// グループを指定しない場合は、Defaultグループに所属するルールを使用してバリデーションされる。
ValidatorUtil.validate(form);

// グループを指定する場合は、指定したグループに所属するルールを使用してバリデーションされる。
ValidatorUtil.validateWithGroup(form, SampleForm.Test1.class);
```
