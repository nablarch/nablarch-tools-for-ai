## 4. 不適切なファイル操作

```java
// ❌ 毎回ファイル開閉
@Override
public Result handle(SqlRow inputData, ExecutionContext context) {
    try (FileWriter writer = new FileWriter("output.csv", true)) {
        String line = inputData.getString("id") + "," + inputData.getString("name");
        writer.write(line);
    }
    return new Success();
}

// ✅ initialize/terminate使用
public class CorrectFileAction extends BatchAction<SqlRow> {
    private ObjectMapper<OutputDto> mapper;
    
    @Override
    protected void initialize(CommandLine command, ExecutionContext context) {
        FilePathSetting setting = FilePathSetting.getInstance();
        File file = setting.getFile("output", "fileName");
        mapper = ObjectMapperFactory.create(OutputDto.class, new FileOutputStream(file));
    }
    
    @Override
    public Result handle(SqlRow inputData, ExecutionContext context) {
        OutputDto dto = EntityUtil.createEntity(OutputDto.class, inputData);
        mapper.write(dto);
        return new Success();
    }
    
    @Override
    protected void terminate(Result result, ExecutionContext context) {
        mapper.close();
    }
}
```

## 10. リソース未解放

```java
// ❌ リソース未解放
public class WrongDataReader implements DataReader<FormClass> {
    private ObjectMapperIterator<FormClass> iterator;
    
    @Override
    public void close(ExecutionContext ctx) {
        // 何もしない
    }
}

// ✅ リソース適切解放
public class CorrectDataReader implements DataReader<FormClass> {
    private ObjectMapperIterator<FormClass> iterator;
    
    @Override
    public void close(ExecutionContext ctx) {
        if (iterator != null) {
            iterator.close();
        }
    }
}

@Override
public Result handle(SqlRow record, ExecutionContext context) {
    ProjectDto dto = EntityUtil.createEntity(ProjectDto.class, record);
    mapper.write(dto); // フレームワークがCSV生成
    return new Success();
}

@Override
protected void terminate(Result result, ExecutionContext context) {
    this.mapper.close(); // リソース解放
}
```

**修正ポイント**:
- `initialize()` でファイルオープン
- `ObjectMapper` でCSV出力
- `terminate()` でリソース解放
