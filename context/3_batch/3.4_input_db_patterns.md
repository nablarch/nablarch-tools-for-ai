# 3.4 データベース入力パターン

## 基本実装パターン

```java
@Override
public DataReader<SqlRow> createReader(ExecutionContext context) {
    DatabaseRecordReader reader = new DatabaseRecordReader();
    SqlPStatement statement = getSqlPStatement("FIND_DATA_BY_STATUS");
    
    // パラメータ設定
    statement.setString(1, "ACTIVE");
    statement.setDate(2, new Date(DateUtil.getDate(BusinessDateUtil.getDate()).getTime()));
    
    reader.setStatement(statement);
    return reader;
}

@Override
public Result handle(SqlRow inputData, ExecutionContext context) {
    // SqlRowからEntity/DTOに変換
    SourceEntity entity = EntityUtil.createEntity(SourceEntity.class, inputData);
    // カラムとDtoの型が違いEntityUtilで設定できない場合は、明示的にsetterを呼ぶ
    entity.setProjectStartDate(inputData.getDate("PROJECT_START_DATE"));

    // エンティティを使用した業務処理
    processEntity(entity);
    return new Success();
}

private void processEntity(SourceEntity entity) {
    // 型安全な処理
    if (entity.getStatus().equals("ACTIVE")) {
        entity.setLastProcessedDate(BusinessDateUtil.getDate());
    }
}
```
