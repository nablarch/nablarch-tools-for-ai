# Form・DTO定義（バッチ用）

## Form使用指針

**Formはバリデーションが必要な場合のみ使用する**

- **外部連携ファイル**: 外部から連携されるファイルなど、入力データが安全でない場合にバリデーションを行いFormクラスを作成する
- **データベース**: データベースなど、入力データが安全な場合は、Formクラスを使用せず、データレコードからEntityクラスを作成して業務ロジックを実行する

## 入力Form（CSV/固定長）

```java
// CSV
@Csv(properties = {"id", "name", "email"}, type = CsvType.CUSTOM)
@CsvFormat(charset = "UTF-8", fieldSeparator = ',', lineSeparator = "\r\n")
public class ImportForm {
    @Domain("id")
    @Required
    private String id;
    
    @Domain("name")
    @Required  
    private String name;
    
    @Domain("email")
    private String email;
    
    private Long lineNumber;
    
    // getter/setter省略
}

// 固定長
@FixedLength(length = 30, charset = "UTF-8")
public class FixedForm {
    @Domain("id")
    @Field(offset = 1, length = 10)
    @Required
    private String id;
    
    @Domain("name")
    @Field(offset = 11, length = 20)
    private String name;
    
    // getter/setter省略
}
```

## 出力DTO（CSV）

```java
@Csv(properties = {"id", "name", "processedDate", "status"}, type = CsvType.CUSTOM)
@CsvFormat(charset = "UTF-8", fieldSeparator = ',', lineSeparator = "\r\n")
public class OutputDto {
    private String id;
    private String name;
    private String processedDate;
    private String status;
    
    // getter/setter省略
}
```

## Entity(自動生成)

```java
@Entity
@Table(name = "DATA_TABLE")
public class DataEntity {
    @Id
    @Column(name = "ID", length = 10)
    private String id;
    
    @Column(name = "NAME", length = 100)
    private String name;
    
    @Column(name = "EMAIL", length = 255)
    private String email;
    
    // getter/setter省略
}
```
