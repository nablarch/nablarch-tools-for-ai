# DataReader実装パターン

## ObjectMapperIterator（ファイル読み込み用）

ObjectMapperにhasNextがないため、イテレータでDataReader実装を簡素化。

```java
public class ObjectMapperIterator<E> implements Iterator<E> {
    private final ObjectMapper<E> mapper;
    private E form;
    
    public ObjectMapperIterator(ObjectMapper<E> mapper) {
        this.mapper = mapper;
        form = mapper.read(); // 初回読み込み
    }
    
    @Override
    public boolean hasNext() { return (form != null); }
    
    @Override
    public E next() {
        final E current = form;
        form = mapper.read(); // 次データ先読み
        return current;
    }
    
    public void close() { mapper.close(); }
}
```

## ファイルDataReader実装

```java
public class FileDataReader implements DataReader<ImportForm> {
    private ObjectMapperIterator<ImportForm> iterator;

    @Override
    public ImportForm read(ExecutionContext ctx) {
        if (iterator == null) initialize();
        return iterator.next();
    }

    @Override
    public boolean hasNext(ExecutionContext ctx) {
        if (iterator == null) initialize();
        return iterator.hasNext();
    }

    @Override
    public void close(ExecutionContext ctx) {
        if (iterator != null) iterator.close();
    }

    private void initialize() {
        FilePathSetting setting = FilePathSetting.getInstance();
        File file = setting.getFileWithoutCreate("input", "fileName");
        try {
            iterator = new ObjectMapperIterator<>(
                ObjectMapperFactory.create(ImportForm.class, new FileInputStream(file)));
        } catch (FileNotFoundException e) {
            throw new IllegalStateException(e);
        }
    }
}
```

## DB用

@Override
public DataReader<SqlRow> createReader(ExecutionContext context) {
    DatabaseRecordReader reader = new DatabaseRecordReader();
    SqlPStatement statement = getSqlPStatement("FIND_DATA");
    statement.setString(1, BusinessDateUtil.getDate());
    reader.setStatement(statement);
    return reader;
}
