# Nablarch データバインド

**機能**: CSV/TSV/固定長ファイル ⇔ Java Beans/Map変換
**制約**: アップロード時は全プロパティString型、ObjectMapperスレッドアンセーフ
**依存**: nablarch-common-databind + nablarch-fw-web-extension(ダウンロード時)

## 基本パターン

**読み込み**:
```java
// Java Beans
try (ObjectMapper<Person> mapper = ObjectMapperFactory.create(Person.class, inputStream)) {
    while ((person = mapper.read()) != null) {
        ValidatorUtil.validate(person);
    }
} catch (InvalidDataFormatException e) { }

// Map
DataBindConfig config = CsvDataBindConfig.DEFAULT.withProperties("age", "name");
try (ObjectMapper<Map> mapper = ObjectMapperFactory.create(Map.class, inputStream, config)) {
    while ((data = mapper.read()) != null) { }
}
```

**書き込み**:
```java
try (ObjectMapper<Person> mapper = ObjectMapperFactory.create(Person.class, outputStream)) {
    for (Person p : list) mapper.write(p);
}
```

## フォーマット指定

**CSV(アノテーション)**:
```java
@Csv(type = Csv.CsvType.DEFAULT, properties = {"age", "name"}, headers = {"年齢", "氏名"})
public class Person { private Integer age; private String name; }

// カスタム
@Csv(type = Csv.CsvType.CUSTOM, properties = {"age", "name"})
@CsvFormat(fieldSeparator = '\t', charset = "UTF-8", quoteMode = CsvDataBindConfig.QuoteMode.ALL)
public class Person { }
```

**固定長(アノテーション)**:
```java
@FixedLength(length = 19, charset = "MS932")
public class Person {
    @Field(offset = 1, length = 3) @Lpad private Integer age;
    @Field(offset = 4, length = 16) @Rpad private String name;
}
```

**DataBindConfig**:
```java
// CSV
DataBindConfig config = CsvDataBindConfig.DEFAULT.withProperties("age", "name");

// 固定長
DataBindConfig config = FixedLengthDataBindConfigBuilder.newBuilder()
    .length(19).singleLayout()
    .field("age", 1, 3, new Lpad.Converter('0')).build();
```

## バリデーション

**アップロード時**: 全プロパティString型 + @Domain
```java
public class PersonUploadForm {
    @Domain("age") private String age;
    @Domain("name") private String name;
}
```

**行番号取得**:
```java
public class Person {
    private Long lineNumber;
    
    @LineNumber  // getterメソッドに付与
    public Long getLineNumber() { return lineNumber; }
    // エラー時: log.error("行番号: {} でエラー", person.getLineNumber());
}
```

## Web連携

**ダウンロード**:
```java
public HttpResponse download(HttpRequest request, ExecutionContext context) {
    Path path = Files.createTempFile(null, null);
    try (ObjectMapper<Person> mapper = ObjectMapperFactory.create(Person.class, Files.newOutputStream(path))) {
        for (Person p : persons) mapper.write(p);
    }
    FileResponse response = new FileResponse(path.toFile(), true);
    response.setContentType("text/csv; charset=Shift_JIS");
    return response;
}
```

**アップロード**:
```java
PartInfo partInfo = request.getPart("uploadFile").get(0);
try (ObjectMapper<Person> mapper = ObjectMapperFactory.create(Person.class, partInfo.getInputStream())) {
    while ((person = mapper.read()) != null) {
        ValidatorUtil.validate(person);
    }
}
```

## CSVセット

| 種類 | 区切り | 空行無視 | ヘッダ | クォート |
|------|--------|----------|--------|----------|
| DEFAULT | , | true | true | NORMAL |
| RFC4180 | , | false | false | NORMAL |
| TSV | \t | false | false | NORMAL |

**クォートモード**: NORMAL(必要時のみ), ALL(全項目)

## マルチレイアウト

**Java Beans**: MultiLayout継承 + RecordIdentifier実装  
**Map**: FixedLengthDataBindConfigBuilder.multiLayout() + recordIdentifier()

## 重要事項

- **リソース管理**: try-with-resources必須  
- **例外**: InvalidDataFormatException, ApplicationException  
- **大量データ**: 一時ファイル + ストリーミング処理
