# 4.4 Service（ビジネスロジック層）

Webアプリケーションにおけるサービス層の実装パターン。

## 実装方針

DaoContextでDBアクセス。テスト時スタブ差し替え可能。

> **重要：Serviceクラスの依存関係**
> 
> ServiceクラスではFormクラスに依存してはいけません：
> - **❌NG**: `ClientForm`、`ProjectSearchForm`などのFormクラスを引数に取る
> - **✅OK**: `Entity`クラス、`Dto`クラス、プリミティブ型を引数に取る
> 
> **理由**: 
> - Formはプレゼンテーション層の関心事
> - Serviceは純粋なビジネスロジック層として独立性を保つ
> - Formの変更がServiceに影響しないようにする

## 基本構成

```java
public class ClientService {
    
    private final DaoContext universalDao;
    
    // デフォルトコンストラクタ（本番用）
    public ClientService() { 
        this(DaoFactory.create()); 
    }
    
    // テスト用コンストラクタ（DIコンテナ用）
    ClientService(DaoContext universalDao) { 
        this.universalDao = universalDao; 
    }
}
```

## 登録処理

### 基本登録
```java
public void create(Client client) {
    // ★引数はEntityクラスを使用（ClientFormは使わない）
    
    // 重複チェック
    validateClientUniqueness(client.getClientName());
    
    // システム日時を設定
    client.setCreatedDate(SystemTimeUtil.getTimestamp());
    
    // 登録実行
    universalDao.insert(client);
}

private void validateClientUniqueness(String clientName) {
    Client condition = new Client();
    condition.setClientName(clientName);
    if (universalDao.exists(Client.class, "FIND_BY_CLIENT_NAME", condition)) {
        throw new DuplicateClientException(clientName);
    }
}
```

### 関連データを含む登録
```java
public void createProject(ProjectDto projectDto) {
    // プロジェクト本体の登録
    Project project = BeanUtil.createAndCopy(Project.class, projectDto);
    project.setCreatedDate(SystemTimeUtil.getTimestamp());
    universalDao.insert(project);
    
    // 関連データ（プロジェクトメンバー）の登録
    // ★注意: PKが自動採番の場合、project.getProjectId()は取得できない
    // 登録後に別途検索するか、シーケンス値を事前取得する必要がある
    for (ProjectMemberDto memberDto : projectDto.getMembers()) {
        ProjectMember member = BeanUtil.createAndCopy(ProjectMember.class, memberDto);
        universalDao.insert(member);
    }
}
```

## 更新処理

### 基本更新
```java
public Project update(Project project) {
    // ★引数はEntityクラスを使用（ProjectUpdateFormは使わない）
    
    // 存在チェック
    Project existing = universalDao.findById(Project.class, project.getProjectId());
    
    // システム日時を設定
    project.setUpdatedDate(SystemTimeUtil.getTimestamp());
    
    // 楽観的ロック付き更新（バージョン番号チェック）
    universalDao.update(project);
    
    return project;
}
```

### 部分更新
```java
public Project updatePartial(ProjectDto projectDto) {
    // 既存データを取得
    Project project = universalDao.findById(Project.class, projectDto.getProjectId());
    
    // null以外の値のみをコピー（部分更新）
    BeanUtil.copy(projectDto, project, CopyOptions.options().excludesNull().build());
    
    // システム日時を設定
    project.setUpdatedDate(SystemTimeUtil.getTimestamp());
    
    // 更新実行
    universalDao.update(project);
    
    return project;
}
```

## 削除処理

### 基本削除
```java
public void delete(Long projectId) {
    // 存在チェック（存在しない場合NoDataException発生）
    Project project = universalDao.findById(Project.class, projectId);
    
    // 削除実行
    universalDao.delete(project);
}
```

### 論理削除
```java
public void deleteLogical(Long projectId) {
    Project project = universalDao.findById(Project.class, projectId);
    
    // 削除フラグを立てる
    project.setDeleteFlag(true);
    project.setDeletedDate(SystemTimeUtil.getTimestamp());
    
    // 更新として実行
    universalDao.update(project);
}
```

### 関連データを含む削除
```java
public void deleteProject(Long projectId) {
    // 存在チェック
    Project project = universalDao.findById(Project.class, projectId);
    
    // 関連データ（プロジェクトメンバー）を削除
    ProjectMember condition = new ProjectMember();
    condition.setProjectId(projectId);
    List<ProjectMember> members = universalDao.findAllBySqlFile(
            ProjectMember.class, "FIND_BY_PROJECT_ID", condition);
    for (ProjectMember member : members) {
        universalDao.delete(member);
    }
    
    // プロジェクト本体を削除
    universalDao.delete(project);
}
```

## 重要ポイント

### Actionとの役割分担
- **Actionの責務**:
  - HTTPリクエスト/レスポンスの処理
  - FormとEntity/Dtoの変換
  - 入力バリデーション（`@InjectForm`）
  - セッション管理
  - Serviceメソッド呼び出し
  
- **Serviceの責動**:
  - ビジネスロジックの実装
  - データベースアクセス
  - 業務ルールのバリデーション
  - 複数のDB操作の統合

```java
// Action側の実装例
public class ProjectAction {
    
    public HttpResponse create(HttpRequest request, ExecutionContext context) {
        ProjectService projectService = new ProjectService();
        
        // ① FormからEntityに変換
        Client client = SessionUtil.get(context, "client");
        
        // ② Serviceでビジネスロジックを実行
        projectService.create(client);
        
        // ③ 画面遷移
        return new HttpResponse(303, "redirect:///action/client/complete");
    }
}

// Service側の実装例
public class ProjectService {
    public void create(Client client) {
        // ① 業務ルールバリデーション
        validateClientUniqueness(client.getClientName());
        
        // ② システム項目設定
        client.setCreatedDate(SystemTimeUtil.getTimestamp());
        
        // ③ DB登録
        universalDao.insert(client);
    }
}
```

### Formクラスへの依存禁止
```java
// ❌NG例
public void createClient(ClientForm form) {
    // ServiceがFormに依存してしまう
}

// ✅OK例
public void create(Client client) {
    // ServiceはEntityに依存
}
```

### DaoContextのインジェクション
```java
public class ProjectService {
    private final DaoContext universalDao;
    
    // 本番用（DaoFactory経由）
    public ProjectService() { 
        this(DaoFactory.create()); 
    }
    
    // テスト用（モックをインジェクション可能）
    ProjectService(DaoContext universalDao) { 
        this.universalDao = universalDao; 
    }
}
```

### 楽観的ロック
- `version` カラムを使用
- `update()` 実行時に自動チェック
- バージョン不一致時は `OptimisticLockException` 発生

### エラーハンドリング
- ビジネスルール違反: `ApplicationException` をスロー
- データ不在: `NoDataException` （`findById`等で自動発生）
- 一意制約違反: 独自例外クラスを定義してスロー

### Serviceクラスの責務
- ビジネスロジックの実装
- データベースアクセス
- トランザクション内処理
- ビジネスルールのバリデーション
