# 2.2 Form（REST特有）

Formで受け取る値のパターン。基本バリデーションは1_common/1.2_validation.md参照。

## 受け取り値パターン

### パスパラメータ（@Path("/{id}")）
```java
public class UserGetForm {
    @Required
    @Domain("id")
    private Long id;  // {id}パスパラメータ
}
```

### クエリパラメータ（URLの?以降）
```java
public class UserSearchForm {
    @Domain("name")
    private String userName;      // ?userName=value
    
    @Domain("page")
    private String page = "1";    // ?page=2
}
```

### リクエストボディ（JSON）
```java
public class UserCreateForm {
    @Required
    @Domain("name")
    private String userName;      // JSON: {"userName": "value"}
}
```

### 一括処理
```java
public class BulkUserForm {
    @Valid
    @Size(max = 100)
    private List<UserCreateForm> users;  // JSON配列
}
```
