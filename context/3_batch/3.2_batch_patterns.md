## 重要な設計原則

1. **フレームワーク制御**: 自前でループを書かない
2. **適切なリソース管理**: initialize/terminateの活用
3. **データリーダーの責務分離**: 読み込み専用クラスとして実装
4. **標準機能の活用**: UniversalDao、EntityUtil、BusinessDateUtilなどを使用
