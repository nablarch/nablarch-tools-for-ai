# 2.3. レスポンス・エラーハンドリング実装

## 基本レスポンス

### DTO直接返却（自動JSON変換）
```java
@GET
@Path("/{id}")
@Produces(MediaType.APPLICATION_JSON)
public UserDto findById(JaxRsHttpRequest request) {
    // DTOを返すと自動的にJSONに変換
    return BeanUtil.createAndCopy(UserDto.class, user);
}
```

### HttpResponse（ステータス制御）
```java
@POST
@Produces(MediaType.APPLICATION_JSON)
public HttpResponse create(UserForm form) {
    User user = BeanUtil.createAndCopy(User.class, form);
    User created = userService.create(user);
    // レスポンスボディを持ちかつステータスコードを設定したい場合はEntityResponseを使用
    return new EntityResponse<User>()
            .setEntity(created)
            .setStatusCode(HttpResponse.Status.CREATED.getStatusCode());
}
```

## エラーハンドリング

### HttpErrorResponse（即座にエラーレスポンス）
```java
@GET
@Path("/{id}")
public UserDto findById(JaxRsHttpRequest request) {
    User user = userService.findById(id);
    if (user == null) {
        throw new HttpErrorResponse(HttpResponse.Status.NOT_FOUND.getStatusCode());
    }
    return BeanUtil.createAndCopy(UserDto.class, user);
}
```

### ApplicationException（バリデーションエラー）
```java
// バリデーションエラー時は自動的にApplicationExceptionが発生
@POST
@Valid
@Consumes(MediaType.APPLICATION_JSON)
public HttpResponse create(UserForm form) {
    // @Validでエラー時はApplicationException → 400レスポンス
    return userService.create(form);
}
```

## 重要ポイント

### レスポンス生成
- **DTO返却**: `@Produces`で自動JSON変換
- **HttpResponse**: ステータス・ヘッダー制御
- **EntityResponse**: エンティティ + ステータス設定

### エラー処理
- **HttpErrorResponse**: 即座にHTTPエラー
- **ApplicationException**: バリデーションエラー（自動発生）
- **ErrorResponseBuilder**: 統一エラーレスポンス生成
