# 悲観ロック（専用）

**前提**: 3.1_form_dto_basics.md（Entity定義）を読み込み済み

```java
// 悲観ロック処理
public class PessimisticLockAction extends BatchAction<SqlRow> {
    @Override
    public DataReader<SqlRow> createReader(ExecutionContext context) {
        DatabaseRecordReader reader = new DatabaseRecordReader();
        SqlPStatement statement = getSqlPStatement("FIND_UNPROCESSED_DATA");
        reader.setStatement(statement);
        return reader;
    }

    @Override
    public Result handle(SqlRow inputData, ExecutionContext context) {
        String id = inputData.getString("ID");
        
        try {
            // 悲観ロックでデータ取得
            ProcessEntity entity = UniversalDao.findBySqlFile(
                ProcessEntity.class, "FIND_BY_ID_WITH_LOCK", Map.of("id", id));
            
            if (entity == null || "PROCESSED".equals(entity.getStatus())) {
                return new Success(); // 他プロセスで処理済み
            }
            
            // 業務処理
            processBusinessLogic(entity);
            
            // ステータス更新
            entity.setStatus("PROCESSED");
            entity.setProcessDate(BusinessDateUtil.getDate());
            UniversalDao.update(entity);
            
        } catch (NoDataException e) {
            // 他プロセスで処理済み
            return new Success();
        }
        
        return new Success();
    }
    
    private void processBusinessLogic(ProcessEntity entity) {
        // 業務ロジック実行
        entity.setProcessedValue(entity.getDataValue().toUpperCase());
    }
}

// ProcessEntity
@Entity
@Table(name = "PROCESS_TABLE")
public class ProcessEntity {
    @Id
    @Column(name = "ID", length = 10)
    private String id;
    
    @Column(name = "STATUS", length = 10)
    private String status;
    
    @Column(name = "DATA_VALUE", length = 100)
    private String dataValue;
    
    @Column(name = "PROCESSED_VALUE", length = 100) 
    private String processedValue;
    
    @Column(name = "PROCESS_DATE", length = 8)
    private String processDate;
    
    @Version
    @Column(name = "VERSION_NO")
    private Long versionNo;
    
    // getter/setter省略
}
```

## 必須SQLファイル

```sql
-- FIND_UNPROCESSED_DATA.sql
FIND_UNPROCESSED_DATA=
SELECT 
    ID,
    STATUS,
    DATA_VALUE,
    VERSION_NO
FROM 
    PROCESS_TABLE
WHERE 
    STATUS = 'UNPROCESSED'
ORDER BY ID

-- FIND_BY_ID_WITH_LOCK.sql
FIND_BY_ID_WITH_LOCK=
SELECT 
    ID,
    STATUS,
    DATA_VALUE,
    PROCESSED_VALUE,
    PROCESS_DATE,
    VERSION_NO
FROM 
    PROCESS_TABLE
WHERE 
    ID = :id
    AND STATUS = 'UNPROCESSED'
FOR UPDATE
```
