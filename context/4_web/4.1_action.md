# 4.1 Action（業務アクションクラス）

NablarchでのWebアプリケーション実装パターン。HttpRequestとHttpResponseを使用。

## 基本実装

### 業務アクションメソッドの必須シグネチャ
```java
public HttpResponse methodName(HttpRequest request, ExecutionContext context)
```

- シグネチャが異なると404エラー発生
- `HttpRequest`: フレームワークから受け渡されるリクエストオブジェクト
- `ExecutionContext`: フレームワークから受け渡される実行コンテキスト
- 戻り値: 遷移先を設定した`HttpResponse`オブジェクト

## URLルーティング設定（routes.xml）

```xml
<routes>
  <!-- 初期表示（GET） -->
  <get path="/action/project" to="Project#list"/>
  
  <!-- 詳細表示（GET、パスパラメータ） -->
  <get path="/action/project/show/:projectId" to="Project#show"/>
  
  <!-- 新規登録画面表示（GET） -->
  <get path="/action/client" to="Client#input"/>
  
  <!-- 登録確認（POST） -->
  <post path="/action/client/confirm" to="Client#confirm"/>
  
  <!-- 登録実行（POST） -->
  <post path="/action/client/create" to="Client#create"/>
  
  <!-- 更新画面表示（GET、パスパラメータ） -->
  <get path="/action/project/edit/:projectId" to="Project#edit"/>
  
  <!-- 更新確認（POST） -->
  <post path="/action/project/confirmOfUpdate" to="Project#confirmOfUpdate"/>
  
  <!-- 更新実行（POST） -->
  <post path="/action/project/update" to="Project#update"/>
  
  <!-- 削除実行（POST） -->
  <post path="/action/project/delete" to="Project#delete"/>
</routes>
```

### ルーティング設定のポイント
- OSSライブラリ `http_request_router` を使用
- 上から順に評価される
- `<get>`、`<post>` でHTTPメソッドを指定
- `to` 属性: `"クラス名#メソッド名"`
- パスパラメータ: `/:変数名` で定義

## 一覧表示（検索）

```java
public class ProjectAction {
    
    @InjectForm(form = ProjectSearchForm.class)
    @OnError(type = ApplicationException.class, path = "/WEB-INF/view/project/index.jsp")
    public HttpResponse list(HttpRequest request, ExecutionContext context) {
        
        // ★バリデーション済みフォームをリクエストスコープから取得
        ProjectSearchForm searchForm = context.getRequestScopedVar("searchForm");
        
        // ★検索条件DtoにBeanUtilで変換（プロパティ名一致で自動マッピング）
        ProjectSearchDto searchCondition = 
                BeanUtil.createAndCopy(ProjectSearchDto.class, searchForm);
        
        // ★ログインユーザー情報を検索条件に設定
        LoginUserPrincipal userContext = SessionUtil.get(context, "userContext");
        searchCondition.setUserId(userContext.getUserId());
        
        // ★Serviceクラスのインスタンス化
        ProjectService projectService = new ProjectService();
        
        // ★Service層経由で検索実行
        List<Project> searchList = projectService.findProjectsByPage(searchCondition, 
                searchCondition.getPageNumber());
        context.setRequestScopedVar("searchResult", searchList);
        
        return new HttpResponse("/WEB-INF/view/project/index.jsp");
    }
}
```

## 詳細表示

```java
@InjectForm(form = ProjectTargetForm.class)
public HttpResponse show(HttpRequest request, ExecutionContext context) {
    
    // ★パスパラメータをバリデーション済みフォームから取得
    ProjectTargetForm targetForm = context.getRequestScopedVar("form");
    LoginUserPrincipal userContext = SessionUtil.get(context, "userContext");
    
    // ★Serviceクラスのインスタンス化
    ProjectService projectService = new ProjectService();
    
    // ★Service層経由で一意キー検索（存在しない場合NoDataException発生 → 404エラー）
    ProjectDto dto = projectService.findProjectWithRelations(
            targetForm.getProjectId(), userContext.getUserId());
    
    context.setRequestScopedVar("project", dto);
    
    return new HttpResponse("/WEB-INF/view/project/detail.jsp");
}
```

## 登録画面の初期表示

```java
public class ClientAction {
    
    public HttpResponse input(HttpRequest request, ExecutionContext context) {
        
        // ★セッションストアのクリーンアップ（二重実行防止）
        SessionUtil.delete(context, "client");
        
        // ★Serviceクラスのインスタンス化
        ClientService clientService = new ClientService();
        
        // ★Service層経由でプルダウン表示用のマスタデータ取得
        EntityList<Industry> industries = clientService.findAllIndustries();
        context.setRequestScopedVar("industries", industries);
        
        return new HttpResponse("/WEB-INF/view/client/create.jsp");
    }
}
```

## 登録確認

```java
@InjectForm(form = ClientForm.class)
@OnError(type = ApplicationException.class, path = "forward:///action/client/input")
public HttpResponse confirm(HttpRequest request, ExecutionContext context) {
    
    // ★バリデーション済みフォームを取得
    ClientForm form = context.getRequestScopedVar("form");
    
    // ★エンティティに変換してセッションストアに保存
    Client client = BeanUtil.createAndCopy(Client.class, form);
    SessionUtil.put(context, "client", client);
    
    // ★Serviceクラスのインスタンス化
    ClientService clientService = new ClientService();
    
    // ★Service層経由で確認画面のプルダウン表示用マスタデータ取得
    EntityList<Industry> industries = clientService.findAllIndustries();
    context.setRequestScopedVar("industries", industries);
    
    return new HttpResponse("/WEB-INF/view/client/confirm.jsp");
}
```

## 登録画面へ戻る

```java
public HttpResponse back(HttpRequest request, ExecutionContext context) {
    
    // ★セッションストアからエンティティを取得
    Client client = SessionUtil.get(context, "client");
    
    // ★フォームに変換してリクエストスコープに設定
    ClientForm form = BeanUtil.createAndCopy(ClientForm.class, client);
    context.setRequestScopedVar("form", form);
    
    // ★内部フォーワードで初期表示処理を呼び出し（マスタデータ再取得のため）
    return new HttpResponse("forward:///action/client/input");
}
```

## 登録実行

```java
public HttpResponse create(HttpRequest request, ExecutionContext context) {
    
    // ★セッションストアから登録データを取得
    Client client = SessionUtil.delete(context, "client");
    
    // ★Serviceクラスのインスタンス化
    ClientService clientService = new ClientService();
    
    // ★Service層経由で登録処理
    clientService.create(client);
    
    // ★完了画面へリダイレクト（POST-REDIRECT-GET パターン）
    return new HttpResponse(303, "redirect:///action/client/complete");
}

public HttpResponse complete(HttpRequest request, ExecutionContext context) {
    return new HttpResponse("/WEB-INF/view/client/complete.jsp");
}
```

## 更新画面の初期表示

```java
@InjectForm(form = ProjectTargetForm.class)
public HttpResponse edit(HttpRequest request, ExecutionContext context) {
    
    // ★セッションストアのクリーンアップ（二重実行防止）
    SessionUtil.delete(context, "project");
    
    // ★現在のデータをService層経由で取得
    ProjectTargetForm targetForm = context.getRequestScopedVar("form");
    LoginUserPrincipal userContext = SessionUtil.get(context, "userContext");
    
    // ★Serviceクラスのインスタンス化
    ProjectService projectService = new ProjectService();
    
    ProjectDto dto = projectService.findProjectWithRelations(
            targetForm.getProjectId(), userContext.getUserId());
    
    // ★編集開始時点のエンティティをセッションストアに保存（楽観的ロック用）
    context.setRequestScopedVar("form", dto);
    SessionUtil.put(context, "project", BeanUtil.createAndCopy(Project.class, dto));
    
    return new HttpResponse("/WEB-INF/view/project/update.jsp");
}
```

## 更新確認

```java
@InjectForm(form = ProjectUpdateForm.class, prefix = "form")
@OnError(type = ApplicationException.class, path = "/WEB-INF/view/project/update.jsp")
public HttpResponse confirmOfUpdate(HttpRequest request, ExecutionContext context) {
    
    ProjectUpdateForm form = context.getRequestScopedVar("form");
    
    // ★DB検索が必要なバリデーション（Service層経由で実施）
    if (form.hasClientId()) {
        // ★Serviceクラスのインスタンス化
        ClientService clientService = new ClientService();
        
        if (!clientService.existsClient(Integer.parseInt(form.getClientId()))) {
            throw new ApplicationException(
                MessageUtil.createMessage(MessageLevel.ERROR,
                    "errors.nothing.client", form.getClientId()));
        }
    }
    
    // ★セッションストアから元データを取得してフォームの値で上書き
    Project project = SessionUtil.get(context, "project");
    BeanUtil.copy(form, project);
    
    context.setRequestScopedVar("form", BeanUtil.createAndCopy(ProjectDto.class, form));
    
    return new HttpResponse("/WEB-INF/view/project/confirmOfUpdate.jsp");
}
```

## 重要ポイント

### Actionクラスの責務
- HTTPリクエストの受付とレスポンス生成
- 入力値のバリデーション（`@InjectForm`）
- FormとEntity/Dtoの変換
- セッション管理
- **ビジネスロジックはService層に委譲**
- **DB操作は直接行わず、Service層経由で実行**

### Service層の利用
```java
public class ProjectAction {
    
    public HttpResponse list(HttpRequest request, ExecutionContext context) {
        // Formからdtoへ変換
        ProjectSearchDto searchCondition = BeanUtil.createAndCopy(...);
        
        // ★Serviceクラスのインスタンス化（メソッド内変数）
        ProjectService projectService = new ProjectService();
        
        // Service層経由でDB操作
        List<Project> result = projectService.findProjectsByPage(searchCondition, pageNumber);
        
        // 結果をリクエストスコープに設定してJSPへ
        context.setRequestScopedVar("searchResult", result);
        return new HttpResponse("/WEB-INF/view/project/index.jsp");
    }
}
```

### @InjectFormアノテーション
- **必須属性**: `form` - フォームクラスを指定
- **任意属性**: `prefix` - JSP内での変数名プレフィックス
- **任意属性**: `name` - リクエストスコープに格納する変数名
- バリデーション実行とリクエストスコープへの格納を自動実行
- フォームは`Serializable`を実装必須

### @OnErrorアノテーション
- バリデーションエラー時の遷移先を指定
- `path="forward://メソッド名"` で内部フォーワード
- `path="/WEB-INF/view/xxx.jsp"` で直接JSPへ
- **⚠️ forwardはHTTPメソッドが元のまま**: POST → forwardでもPOSTのまま
  ```java
  // ❌ NG例: confirm(POST) → forward → input(GET定義のみ) で404
  @OnError(type = ApplicationException.class, path = "forward:///action/project/create/input")
  public HttpResponse confirm(HttpRequest request, ExecutionContext context) {}
  // routes.xml: <get path="/action/project/create/input"/> のみ → POSTで404
  
  // ✅ OK例: forward先にPOSTルーティングも定義
  @OnError(type = ApplicationException.class, path = "forward:///action/project/create/input")
  public HttpResponse confirm(HttpRequest request, ExecutionContext context) {}
  // routes.xml: GET/POST両方定義
  // <get path="/action/project/create/input" to="ProjectCreate#input"/>
  // <post path="/action/project/create/input" to="ProjectCreate#input"/>
  ```

### セッションストアの使い方
- **登録**: `SessionUtil.put(context, "key", object)`
- **取得**: `SessionUtil.get(context, "key")`
- **削除**: `SessionUtil.delete(context, "key")`
- フォームは直接格納せず、エンティティに変換してから格納
- 処理完了後は必ずクリーンアップ
- 初期表示時にも削除（二重実行防止）

### リクエストスコープの使い方
- **登録**: `context.setRequestScopedVar("key", object)`
- **取得**: `context.getRequestScopedVar("key")`
- JSPへのデータ受け渡しに使用
- バリデーション済みフォームの取得に使用

### レスポンスの種類
- **JSP表示**: `new HttpResponse("/WEB-INF/view/xxx.jsp")`
- **内部フォーワード**: `new HttpResponse("forward://メソッド名")`
  - ⚠️ HTTPメソッドは元のリクエストのまま（POST → forward → POSTのまま）
  - routes.xmlでforwerd先のメソッドに対応するHTTPメソッドのルートが必要
- **リダイレクト**: `new HttpResponse(303, "redirect:///action/xxx")`
- POST-REDIRECT-GETパターンでは303リダイレクトを使用

### パスパラメータの取得
- routes.xmlで `/:変数名` を定義
- フォームにプロパティを定義
- `@InjectForm` でバリデーションとマッピング
- リクエストスコープから取得

### NoDataException
- `UniversalDao.findBySqlFile()` でデータ不在時に発生
- カスタムエラーハンドラで404エラー画面へ遷移可能
