# 1.7 日付・時刻ユーティリティ

## BusinessDateUtil（業務日付）

### 基本的な使用方法

```java
// 業務日付の取得（String型 yyyyMMdd形式）
String businessDateStr = BusinessDateUtil.getDate();  // "20241225"

// Date型への変換
Date businessDate = DateUtil.getDate(BusinessDateUtil.getDate());

// java.sql.Date型への変換（データベース用）
java.sql.Date sqlBusinessDate = new java.sql.Date(DateUtil.getDate(BusinessDateUtil.getDate()).getTime());
```

> **重要：BusinessDateUtilの戻り値**  
> `BusinessDateUtil.getDate()`は**String型**で**yyyyMMdd形式**（スラッシュなし）を返します。  
> 直接parseせず、必ず`DateUtil.getDate()`を経由してください。

### 実装パターン

```java
// ✅正しいパターン
public class SampleBatchAction extends BatchAction<InputData> {
    @Override
    public Result handle(InputData inputData, ExecutionContext context) {
        // 業務日付をjava.sql.Date型で取得
        java.sql.Date businessDate = new java.sql.Date(
            DateUtil.getDate(BusinessDateUtil.getDate()).getTime()
        );
        
        // エンティティに設定
        DataEntity entity = new DataEntity();
        entity.setProcessDate(businessDate);
        
        return new Success();
    }
}

// ❌間違ったパターン
SimpleDateFormat formatter = new SimpleDateFormat("yyyy/MM/dd");  // 不要
Date date = formatter.parse(BusinessDateUtil.getDate());          // エラー
```

## DateUtil（日付変換）

### 主要メソッド

```java
// String(yyyyMMdd) → Date変換
Date date = DateUtil.getDate("20241225");

// Date → String(yyyyMMdd)変換  
String dateStr = DateUtil.formatDate(new Date(), "yyyyMMdd");

// 日付加算（String → String）
String tomorrow = DateUtil.addDay("20241225", 1);      // "20241226"
String nextMonth = DateUtil.addMonth("20241225", 1);   // "20250125"

// 日付間の日数・月数計算
long days = DateUtil.getDays("20241225", "20241231");   // 6日
int months = DateUtil.getMonths("202412", "202501");    // 1ヶ月

// 月末日取得
String monthEnd = DateUtil.getMonthEndDate("202412");  // "20241231"
```

### バッチ処理での典型的な使用例

```java
public class DailyBatchAction extends BatchAction<SqlRow> {
    @Override
    public Result handle(SqlRow inputData, ExecutionContext context) {
        // 業務日付取得
        String businessDateStr = BusinessDateUtil.getDate();
        Date businessDate = DateUtil.getDate(businessDateStr);
        
        // 処理対象期間の計算
        String startDateStr = DateUtil.addDay(businessDateStr, -7);  // 一週間前
        Date startDate = DateUtil.getDate(startDateStr);
        Date endDate = businessDate;
        
        // SQLパラメータ用にjava.sql.Date変換
        java.sql.Date sqlStartDate = new java.sql.Date(startDate.getTime());
        java.sql.Date sqlEndDate = new java.sql.Date(endDate.getTime());
        
        // データベース処理
        processData(sqlStartDate, sqlEndDate);
        
        return new Success();
    }
}
```

## 注意事項

### 業務日付の形式

> **重要：**  
> - `BusinessDateUtil.getDate()`：**yyyyMMdd形式**（例：20241225）
> - スラッシュ区切り（yyyy/MM/dd）ではない
> - 必ず`DateUtil.getDate()`で変換してから使用

### データベース用日付変換

```java
// 標準的な変換パターン
java.sql.Date sqlDate = new java.sql.Date(
    DateUtil.getDate(BusinessDateUtil.getDate()).getTime()
);

// Timestampが必要な場合
java.sql.Timestamp timestamp = new java.sql.Timestamp(
    DateUtil.getDate(BusinessDateUtil.getDate()).getTime()
);
```

### 日付フォーマットが必要な場合

```java
// 画面表示用（yyyy/MM/dd形式）
String displayDate = DateUtil.formatDate(
    DateUtil.getDate(BusinessDateUtil.getDate()), 
    "yyyy/MM/dd"
);

// String → String フォーマット変換（yyyyMMdd → yyyy/MM/dd）
String formattedDate = DateUtil.formatDate(BusinessDateUtil.getDate(), "yyyy/MM/dd");

// ファイル名用（yyyyMMdd形式はそのまま使用）
String fileName = "data_" + BusinessDateUtil.getDate() + ".csv";  // "data_20241225.csv"

// 日付バリデーション
boolean isValid = DateUtil.isValid("20241225", "yyyyMMdd");
```
