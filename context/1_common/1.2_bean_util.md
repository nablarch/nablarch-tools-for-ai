# 1.2 BeanUtil詳細ガイド

BeanUtilはForm ↔ Entity/DTO、Map ↔ Entity/DTOの変換に使用します。

## 主要メソッド
```java
// 新しいオブジェクトを作成してコピー
UserDto dto = BeanUtil.createAndCopy(UserDto.class, form);

// 既存のオブジェクトにコピー
BeanUtil.copy(form, entity);

// プロパティ値の取得・設定
String name = (String) BeanUtil.getProperty(user, "name");
BeanUtil.setProperty(user, "name", "新しい名前");

// Mapとの相互変換
Map<String, Object> map = BeanUtil.createMapAndCopy(user);
User user = BeanUtil.createAndCopy(User.class, map);
```

## Form ↔ Entity 変換パターン

### 入力画面での変換（Form → Entity）
```java
@InjectForm(form = UserForm.class, name = "form")
public HttpResponse create(HttpRequest request, ExecutionContext context) {
    UserForm form = context.getRequestScopedVar("form");
    
    // FormからEntityに変換
    User user = BeanUtil.createAndCopy(User.class, form);
    
    UniversalDao.insert(user);
    return new HttpResponse("redirect://complete");
}
```

### 編集画面での変換（Entity → Form）
```java
public HttpResponse input(HttpRequest request, ExecutionContext context) {
    // データベースからEntity取得
    User user = UniversalDao.findById(User.class, userId);
    
    // EntityからFormに変換して画面表示用に設定
    UserForm form = BeanUtil.createAndCopy(UserForm.class, user);
    context.setRequestScopedVar("form", form);
    
    return new HttpResponse("/WEB-INF/view/user/input.jsp");
}
```

### 更新処理での変換
```java
@InjectForm(form = UserForm.class, name = "form")
public HttpResponse update(HttpRequest request, ExecutionContext context) {
    UserForm form = context.getRequestScopedVar("form");
    
    // セッションから元のEntityを取得
    User user = SessionUtil.get(context, "user");
    
    // Formの値をEntityに上書きコピー
    BeanUtil.copy(form, user);
    
    UniversalDao.update(user);
    return new HttpResponse("redirect://complete");
}
```

## 検索条件での変換パターン

### 検索フォーム → 検索条件Bean
```java
@InjectForm(form = ProjectSearchForm.class, name = "searchForm")
public HttpResponse search(HttpRequest request, ExecutionContext context) {
    ProjectSearchForm searchForm = context.getRequestScopedVar("searchForm");
    
    // 検索フォームから検索条件Beanに変換
    ProjectSearchDto searchDto = BeanUtil.createAndCopy(ProjectSearchDto.class, searchForm);
    
    // データベース検索実行
    EntityList<Project> projects = UniversalDao.findAllBySqlFile(
        Project.class, "SEARCH_PROJECT", searchDto);
    
    context.setRequestScopedVar("projects", projects);
    return new HttpResponse("/WEB-INF/view/project/list.jsp");
}
```

## ネストしたオブジェクトの扱い

### ネストしたBeanのコピー
```java
public class User {
    private String name;
    private Address address;  // ネストしたBean
    // getter/setter省略
}

public class Address {
    private String postNo;
    private String prefecture;
    // getter/setter省略
}

// ネストしたBeanも含めて完全コピー
User originalUser = createUser();
User copiedUser = BeanUtil.createAndCopy(User.class, originalUser);
```

### Mapでのネストプロパティ指定
```java
Map<String, Object> userMap = new HashMap<>();
userMap.put("name", "田中太郎");
userMap.put("address.postNo", "123-4567");  // ドット記法でネスト指定
userMap.put("address.prefecture", "東京都");

User user = BeanUtil.createAndCopy(User.class, userMap);
// user.getAddress().getPostNo() → "123-4567"
```

## 自動型変換機能

### 基本型の自動変換
```java
// BeanUtilが自動で型変換を行う
Map<String, Object> data = new HashMap<>();
data.put("id", "123");        // String → Long
data.put("age", "25");        // String → Integer
data.put("active", "true");   // String → Boolean

User user = BeanUtil.createAndCopy(User.class, data);
```

### 日付フォーマット変換
```java
// CopyOptionsで日付フォーマットを指定
CopyOptions options = CopyOptions.options()
    .datePatternByName("birthday", "yyyy/MM/dd")
    .build();

UserForm form = BeanUtil.createAndCopy(UserForm.class, data, options);
```

## RESTサービスでの使用例

### リクエストボディの変換
```java
@POST
@Consumes(MediaType.APPLICATION_JSON)
@Valid
public HttpResponse create(UserCreateForm form) {
    // FormからEntityに変換
    User user = BeanUtil.createAndCopy(User.class, form);
    
    UniversalDao.insert(user);
    return new HttpResponse(HttpResponse.Status.CREATED.getStatusCode());
}
```

### レスポンスボディの変換
```java
@GET
@Path("/{userId}")
@Produces(MediaType.APPLICATION_JSON)
public UserDto findById(@PathParam("userId") String userId) {
    User user = UniversalDao.findById(User.class, Long.valueOf(userId));
    
    // EntityからDTOに変換してJSONレスポンス用に返却
    return BeanUtil.createAndCopy(UserDto.class, user);
}
```

## セッションストアとの連携

### セッション保存時の変換
```java
public HttpResponse input(HttpRequest request, ExecutionContext context) {
    UserForm form = context.getRequestScopedVar("form");
    
    // FormからEntityに変換してセッションに保存
    User user = BeanUtil.createAndCopy(User.class, form);
    SessionUtil.put(context, "user", user);
    
    return new HttpResponse("/WEB-INF/view/user/confirm.jsp");
}
```

### セッション取得時の変換
```java
public HttpResponse back(HttpRequest request, ExecutionContext context) {
    // セッションからEntityを取得
    User user = SessionUtil.get(context, "user");
    
    // EntityからFormに変換して入力画面に戻す
    UserForm form = BeanUtil.createAndCopy(UserForm.class, user);
    context.setRequestScopedVar("form", form);
    
    return new HttpResponse("/WEB-INF/view/user/input.jsp");
}
```

## バッチ処理での使用例

### ファイルデータの変換
```java
// CSVから読み込んだデータをEntityに変換
try (ObjectMapper<UserCsvForm> mapper = ObjectMapperFactory.create(
        UserCsvForm.class, inputStream)) {
    
    UserCsvForm csvForm;
    while ((csvForm = mapper.read()) != null) {
        // CSVフォームからEntityに変換
        User user = BeanUtil.createAndCopy(User.class, csvForm);
        UniversalDao.insert(user);
    }
}
```

## 重要な注意事項

### 使用範囲の制限
- **SqlRowからの変換はEntityUtil.createEntity()を使用（BeanUtilは使用不可）**
- BeanUtilはForm ↔ Entity/DTO、Map ↔ Entity/DTOの変換専用
- EntityUtilとの使い分けは「1.8_object_conversion.md」を参照

### プロパティ名の一致
- **コピー元とコピー先で同じ名前のプロパティのみコピーされる**
- 存在しないプロパティは無視される
- getter/setterメソッドを使用してアクセス

### 型変換の注意点
```java
// 精度の問題に注意
Long bigValue = 9999999999L;
Map<String, Object> data = new HashMap<>();
data.put("value", bigValue);

// Integer型のプロパティにLongを設定する場合、
// 事前にバリデーションで範囲チェックが必要
IntegerForm form = BeanUtil.createAndCopy(IntegerForm.class, data);
```

### List型の制限
```java
// List型の型パラメータは直接サポートされない
public class ItemForm<T> {
    private List<T> items;  // 型パラメータはサポートされない
}

// 具象クラスでgetterをオーバーライドして対応
public class UserItemForm extends ItemForm<User> {
    @Override
    public List<User> getItems() {
        return super.getItems();
    }
}
```

## BeanUtil使用場面

1. **Form ↔ Entity/DTO変換**: 画面入力・表示時
2. **Map ↔ Entity/DTO変換**: 一般的なデータ変換
3. **検索条件の組み立て**: SearchForm → SearchDto
4. **セッション管理**: 一時保存時の型変換
5. **ファイルデータ変換**: CSVフォーム → Entity等
