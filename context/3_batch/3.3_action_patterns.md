# BatchAction実装パターン

## 基本構造

```java
public class XxxBatchAction extends BatchAction<InputType> {
    @Override
    public DataReader<InputType> createReader(ExecutionContext context) {
        return new XxxDataReader();  // 必須
    }
    
    @Override
    public Result handle(InputType inputData, ExecutionContext context) {
        // 1レコード処理
        return new Success();  // 必須
    }
    
    @Override
    protected void initialize(CommandLine command, ExecutionContext context) {
        // 初期化処理（任意）
    }
    
    @Override
    protected void terminate(Result result, ExecutionContext context) {
        // 終了処理（任意）
    }
}
```

## パターン別実装

### 1. ファイル→DB

```java
public class FileToDbAction extends BatchAction<ImportForm> {
    @Override
    public DataReader<ImportForm> createReader(ExecutionContext context) {
        return new FileDataReader();
    }

    @Override
    @ValidateData
    public Result handle(ImportForm inputData, ExecutionContext context) {
        DataEntity entity = BeanUtil.createAndCopy(DataEntity.class, inputData);
        UniversalDao.insert(entity);
        return new Success();
    }
}
```

### 2. DB→ファイル

```java
public class DbToFileAction extends BatchAction<SqlRow> {
    private ObjectMapper<OutputDto> mapper;

    @Override
    protected void initialize(CommandLine command, ExecutionContext context) {
        FilePathSetting setting = FilePathSetting.getInstance();
        File file = setting.getFile("output", "fileName");
        mapper = ObjectMapperFactory.create(OutputDto.class, new FileOutputStream(file));
    }

    @Override
    public DataReader<SqlRow> createReader(ExecutionContext context) {
        DatabaseRecordReader reader = new DatabaseRecordReader();
        SqlPStatement statement = getSqlPStatement("FIND_DATA");
        reader.setStatement(statement);
        return reader;
    }

    @Override
    public Result handle(SqlRow record, ExecutionContext context) {
        OutputDto dto = EntityUtil.createEntity(OutputDto.class, record);
        mapper.write(dto);
        return new Success();
    }

    @Override
    protected void terminate(Result result, ExecutionContext context) {
        mapper.close();  // 必須
    }
}
```

### 3. DB→DB

```java
public class DbToDbAction extends BatchAction<SqlRow> {
    @Override
    public DataReader<SqlRow> createReader(ExecutionContext context) {
        DatabaseRecordReader reader = new DatabaseRecordReader();
        SqlPStatement statement = getSqlPStatement("FIND_SOURCE_DATA");
        reader.setStatement(statement);
        return reader;
    }

    @Override
    public Result handle(SqlRow inputData, ExecutionContext context) {
        TargetEntity entity = EntityUtil.createEntity(TargetEntity.class, inputData);
        entity.setProcessedDate(BusinessDateUtil.getDate());
        
        if (UniversalDao.exists(TargetEntity.class, "id", entity.getId())) {
            UniversalDao.update(entity);
        } else {
            UniversalDao.insert(entity);
        }
        return new Success();
    }
}
```

## エラーハンドリング

```java
@Override
public Result handle(SqlRow inputData, ExecutionContext context) {
    try {
        // 業務処理
        processRecord(inputData);
        return new Success();
    } catch (Exception e) {
        // ログ出力
        LOGGER.warn("処理エラー ID:{}", inputData.getString("ID"), e);
        return new Success(); // 処理継続
    }
}
```
