# 1.6 ファイルパス管理

## 基本概念
**ファイルパス管理**: ディレクトリや拡張子を論理名で管理し、ファイル操作を簡素化

## 設定方法

### FilePathSetting設定
```xml
<component name="filePathSetting" class="nablarch.core.util.FilePathSetting">
    <!-- ディレクトリの設定 -->
    <property name="basePathSettings">
        <map>
            <entry key="csv-input" value="file:/var/nablarch/input" />
            <entry key="csv-output" value="file:/var/nablarch/output" />
            <entry key="dat-input" value="file:/var/nablarch/input" />
            <entry key="fixed-file-input" value="file:/var/nablarch/input" />
            <entry key="log-output" value="file:/var/nablarch/logs" />
        </map>
    </property>

    <!-- 拡張子の設定 -->
    <property name="fileExtensions">
        <map>
            <entry key="csv-input" value="csv" />
            <entry key="csv-output" value="csv" />
            <entry key="dat-input" value="dat" />
            <entry key="log-output" value="log" />
            <!-- fixed-file-inputは拡張子なし -->
        </map>
    </property>
</component>
```

## 実装パターン

### ファイルパス取得
```java
@Resource
private FilePathSetting filePathSetting;

// ファイル取得（拡張子あり）: /var/nablarch/input/users.csv
File inputFile = filePathSetting.getFileWithoutCreate("csv-input", "users");

// ディレクトリ取得: /var/nablarch/output
File outputDir = filePathSetting.getBaseDirectory("csv-output");

// ファイル取得（拡張子なし）: /var/nablarch/input/users
File fixedFile = filePathSetting.getFileWithoutCreate("fixed-file-input", "users");
```

### バッチ処理での使用例
```java
public class FileBatchAction extends BatchAction<SqlRow> {
    
    @Resource
    private FilePathSetting filePathSetting;
    
    @Override
    public DataReader<SqlRow> createReader(ExecutionContext context) {
        // 入力ファイルパス取得
        File inputFile = filePathSetting.getFileWithoutCreate("csv-input", "batch_input");
        
        FileDataReader reader = new FileDataReader();
        reader.setDataFile(inputFile);
        return reader;
    }
    
    @Override
    public Result handle(SqlRow inputData, ExecutionContext context) {
        // 出力ファイルパス取得
        File outputFile = filePathSetting.getFileWithoutCreate("csv-output", "batch_result");
        
        // ファイル書き込み処理
        writeToFile(outputFile, processData(inputData));
        return new Success();
    }
}
```

### Web処理でのファイルアップロード
```java
@InjectForm(form = FileUploadForm.class)
public HttpResponse upload(HttpRequest request, ExecutionContext context) {
    FileUploadForm form = context.getRequestScopedVar("form");
    
    // アップロードファイル保存先取得
    File uploadDir = filePathSetting.getBaseDirectory("upload-temp");
    File savedFile = new File(uploadDir, form.getFile().getName());
    
    // ファイル保存
    saveUploadedFile(form.getFile(), savedFile);
    
    return HttpResponse.redirect("upload/complete");
}
```

## 注意事項

### スキーム指定
- **file**: 物理ファイルパス（推奨）
- **classpath**: クラスパス配下（一部サーバで制限あり）
- **省略時**: classpathとして扱われる

### 制限事項
- **JBoss/Wildfly**: VFSのためclasspathスキーム使用不可
- **パスにスペース**: 含めることができない
- **JAR内パス**: classpathスキームでは指定不可

### 設定のポイント
```xml
<!-- ✅推奨：fileスキームを使用 -->
<entry key="data-input" value="file:/var/nablarch/data" />

<!-- ❌非推奨：classpathスキーム（サーバ制限あり） -->
<entry key="data-input" value="classpath:data" />

<!-- ❌NG：スペースを含むパス -->
<entry key="data-input" value="file:/Program Files/nablarch" />
```
