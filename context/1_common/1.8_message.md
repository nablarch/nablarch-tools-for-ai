# 1.8 メッセージ管理

## 定義・使用
```properties
# messages.properties
errors.login.alreadyExist=入力されたログインIDは既に登録されています。
success.upload.project={0}件のプロジェクトを登録しました。
user.welcome.message={userName}さん、こんにちは。最終ログイン：{lastLogin}
```

```java
// 基本メッセージ
Message message = MessageUtil.createMessage(MessageLevel.ERROR, "errors.login.alreadyExist");
throw new ApplicationException(message);

// パラメータ埋め込み（配列）
MessageUtil.createMessage(MessageLevel.INFO, "success.upload.project", projects.size());

// パラメータ埋め込み（Map）
Map<String, Object> options = new HashMap<>();
options.put("userName", user.getName());
MessageUtil.createMessage(MessageLevel.INFO, "user.welcome.message", options);
```

## Web表示
```java
// Action
context.setRequestScopedVar("message", MessageUtil.createMessage(MessageLevel.INFO, "success.update.project").formatMessage());
```
```jsp
<!-- JSP -->
<n:message messageId="label.user.register.title" />
<n:write name="message" />
```

### Batch: ログ出力
```java
public class ProjectBatchAction extends BatchAction<ProjectForm> {
    @Override
    public Result handle(ProjectForm inputData, ExecutionContext ctx) {
        try {
            // 業務処理...
        } catch (ApplicationException e) {
            LOGGER.logWarn(MessageUtil.createMessage(MessageLevel.WARN, 
                "batch.warning.skip", inputData.getProjectId()).formatMessage());
        }
        return new Success();
    }
}
```
