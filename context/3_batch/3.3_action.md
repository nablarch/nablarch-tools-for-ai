```java
public class XxxBatchAction extends BatchAction<InputType> {
    @Override
    public DataReader<InputType> createReader(ExecutionContext context) {
        return new XxxDataReader();  // 必須
    }
    
    @Override
    public Result handle(InputType inputData, ExecutionContext context) {
        // 1レコード処理
        return new Success();  // 必須
    }
    
    @Override
    protected void initialize(CommandLine command, ExecutionContext context) {
        // 初期化処理（任意）
    }
    
    @Override
    protected void terminate(Result result, ExecutionContext context) {
        // 終了処理（任意）
    }
}
```

## エラーハンドリング

### 基本的なエラーハンドリング（処理継続）

```java
@Override
public Result handle(SqlRow inputData, ExecutionContext context) {
    try {
        // 業務処理
        processRecord(inputData);
        return new Success();
    } catch (Exception e) {
        // ログ出力
        LOGGER.warn("処理エラー ID:{}", inputData.getString("ID"), e);
        return new Success(); // 処理継続
    }
}
```

### バリデーションエラー時のApplicationException

```java
@Override
@ValidateData
public Result handle(ImportForm inputData, ExecutionContext context) {
    try {
        // 業務ルールチェック
        validateBusinessRules(inputData);
        
        // 正常処理
        DataEntity entity = BeanUtil.createAndCopy(DataEntity.class, inputData);
        UniversalDao.insert(entity);
        return new Success();
        
    } catch (ApplicationException e) {
        // バリデーションエラーはApplicationException
        LOGGER.warn("バリデーションエラー 行:{}, エラー:{}", 
                   inputData.getLineNumber(), e.getMessages());
        throw e; // バッチ処理停止
    } catch (Exception e) {
        // その他のエラー
        LOGGER.error("システムエラー 行:{}", inputData.getLineNumber(), e);
        throw new ApplicationException("システムエラーが発生しました", e);
    }
}

private void validateBusinessRules(ImportForm form) {
    List<Message> messages = new ArrayList<>();
    
    // 重複チェック
    if (UniversalDao.exists(DataEntity.class, "FIND_BY_ID", form.getId())) {
        messages.add(MessageUtil.createMessage(MessageLevel.ERROR, 
                     "duplicate.id", form.getId()));
    }
    
    // 参照整合性チェック
    if (!UniversalDao.exists(MasterEntity.class, "FIND_BY_CODE", form.getMasterCode())) {
        messages.add(MessageUtil.createMessage(MessageLevel.ERROR, 
                     "not.found.master", form.getMasterCode()));
    }
    
    if (!messages.isEmpty()) {
        throw new ApplicationException(messages);
    }
}
```
