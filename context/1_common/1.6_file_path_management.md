# 1.6 ファイルパス管理

## 基本概念
**ファイルパス管理**: ディレクトリや拡張子を論理名で管理し、ファイル操作を簡素化

## 設定方法

### FilePathSetting設定
```xml
<component name="filePathSetting" class="nablarch.core.util.FilePathSetting">
    <!-- ディレクトリの設定 -->
    <property name="basePathSettings">
        <map>
            <entry key="csv-input" value="file:/var/nablarch/input" />
            <entry key="csv-output" value="file:/var/nablarch/output" />
            <entry key="dat-input" value="file:/var/nablarch/input" />
            <entry key="fixed-file-input" value="file:/var/nablarch/input" />
            <entry key="log-output" value="file:/var/nablarch/logs" />
        </map>
    </property>

    <!-- 拡張子の設定 -->
    <property name="fileExtensions">
        <map>
            <entry key="csv-input" value="csv" />
            <entry key="csv-output" value="csv" />
            <entry key="dat-input" value="dat" />
            <entry key="log-output" value="log" />
            <!-- fixed-file-inputは拡張子なし -->
        </map>
    </property>
</component>
```

## 実装パターン

### ファイルパス取得
```java
private FilePathSetting filePathSetting;

// ファイル取得（拡張子あり）: /var/nablarch/input/users.csv
File inputFile = filePathSetting.getFileWithoutCreate("csv-input", "users");

// ディレクトリ取得: /var/nablarch/output
File outputDir = filePathSetting.getBaseDirectory("csv-output");

// ファイル取得（拡張子なし）: /var/nablarch/input/users
File fixedFile = filePathSetting.getFileWithoutCreate("fixed-file-input", "users");
```

### バッチ処理での使用例
```java
public class ImportZipCodeFileAction extends BatchAction<ZipCodeForm> {
    @Override
    public DataReader<ZipCodeForm> createReader(ExecutionContext ctx) { return new ZipCodeFileReader(); }
}

public class ZipCodeFileReader implements DataReader<ZipCodeForm> {
    private ObjectMapperIterator<ZipCodeForm> iterator;
    @Override
    public ZipCodeForm read(ExecutionContext ctx) {
        if (iterator == null) {
            initialize();
        }
        return iterator.next();
    }
    @Override
    public boolean hasNext(ExecutionContext ctx) {
        if (iterator == null) {
            initialize();
        }
        return iterator.hasNext();
    }
    @Override
    public void close(ExecutionContext ctx) {
        iterator.close();
    }
    private void initialize() {
        FilePathSetting filePathSetting = FilePathSetting.getInstance();
        File zipCodeFile = filePathSetting.getFileWithoutCreate("csv-input", "importZipCode");
        try {
            iterator = new ObjectMapperIterator<>(ObjectMapperFactory.create(ZipCodeForm.class,
                    new FileInputStream(zipCodeFile)));
        } catch (FileNotFoundException e) {
            throw new IllegalStateException(e);
        }
    }
}
```

```java
public class ExportProjectsInPeriodAction extends BatchAction<SqlRow> {
    private ObjectMapper<ProjectDto> mapper;
    @Override
    protected void initialize(CommandLine command, ExecutionContext context) {
        FilePathSetting filePathSetting = FilePathSetting.getInstance();
        File output = filePathSetting.getFile("csv_output",
                OUTPUT_FILE_NAME);
        try {
            FileOutputStream outputStream = new FileOutputStream(output);
            this.mapper = ObjectMapperFactory.create(ProjectDto.class, outputStream);
        } catch (FileNotFoundException e) {
            throw new IllegalStateException(e);
        }
    }
    @Override
    public Result handle(SqlRow record, ExecutionContext context) {
        ProjectDto dto = EntityUtil.createEntity(ProjectDto.class, record);
        mapper.write(dto);
        return new Success();
    }

    @Override
    protected void terminate(Result result, ExecutionContext context) {
        this.mapper.close();
    }
}
```

## 注意事項

### スキーム指定
- **file**: 物理ファイルパス（推奨）
- **classpath**: クラスパス配下（一部サーバで制限あり）
- **省略時**: classpathとして扱われる

### 制限事項
- **JBoss/Wildfly**: VFSのためclasspathスキーム使用不可
- **パスにスペース**: 含めることができない
- **JAR内パス**: classpathスキームでは指定不可

### 設定のポイント
```xml
<!-- ✅推奨：fileスキームを使用 -->
<entry key="data-input" value="file:/var/nablarch/data" />

<!-- ❌非推奨：classpathスキーム（サーバ制限あり） -->
<entry key="data-input" value="classpath:data" />

<!-- ❌NG：スペースを含むパス -->
<entry key="data-input" value="file:/Program Files/nablarch" />
```
