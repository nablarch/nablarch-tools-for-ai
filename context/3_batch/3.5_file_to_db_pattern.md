# ファイルからDB登録（専用）

**前提**: 3.1_form_dto_basics.md（Form・Entity定義）と 3.2_reader_patterns.md（FileDataReader）を読み込み済み

```java
public class FileToDbAction extends BatchAction<ImportForm> {
    @Override
    public DataReader<ImportForm> createReader(ExecutionContext context) {
        return new FileDataReader();
    }

    @Override
    @ValidateData
    public Result handle(ImportForm inputData, ExecutionContext context) {
        DataEntity entity = BeanUtil.createAndCopy(DataEntity.class, inputData);
        UniversalDao.insert(entity);
        return new Success();
    }
}
```
