# 4.4 Service（ビジネスロジック層）

Webアプリケーションにおけるサービス層の実装パターン。

## 実装方針

DaoContextでDBアクセス。テスト時スタブ差し替え可能。

> **重要：Serviceクラスの依存関係**
> 
> ServiceクラスではFormクラスに依存してはいけません：
> - **❌NG**: `ClientForm`、`ProjectSearchForm`などのFormクラスを引数に取る
> - **✅OK**: `Entity`クラス、`Dto`クラス、プリミティブ型を引数に取る
> 
> **理由**: 
> - Formはプレゼンテーション層の関心事
> - Serviceは純粋なビジネスロジック層として独立性を保つ
> - Formの変更がServiceに影響しないようにする

## 基本構成

```java
public class ClientService {
    
    private final DaoContext universalDao;
    
    // デフォルトコンストラクタ（本番用）
    public ClientService() { 
        this(DaoFactory.create()); 
    }
    
    // テスト用コンストラクタ（DIコンテナ用）
    ClientService(DaoContext universalDao) { 
        this.universalDao = universalDao; 
    }
}
```

## 登録処理

### 基本登録
```java
public void create(Client client) {
    // ★引数はEntityクラスを使用（ClientFormは使わない）
    
    // 重複チェック
    validateClientUniqueness(client.getClientName());
    
    // システム日時を設定
    client.setCreatedDate(SystemTimeUtil.getTimestamp());
    
    // 登録実行
    universalDao.insert(client);
}

private void validateClientUniqueness(String clientName) {
    Client condition = new Client();
    condition.setClientName(clientName);
    if (universalDao.countBySqlFile(Client.class, "FIND_BY_CLIENT_NAME", condition) > 0) {
        throw new DuplicateClientException(clientName);
    }
}
```

### 関連データを含む登録
```java
public void createProject(ProjectDto projectDto) {
    // プロジェクト本体の登録
    Project project = BeanUtil.createAndCopy(Project.class, projectDto);
    project.setCreatedDate(SystemTimeUtil.getTimestamp());
    universalDao.insert(project);
    
    // 関連データ（プロジェクトメンバー）の登録
    // ★注意: PKが自動採番の場合、project.getProjectId()は取得できない
    // 登録後に別途検索するか、シーケンス値を事前取得する必要がある
    for (ProjectMemberDto memberDto : projectDto.getMembers()) {
        ProjectMember member = BeanUtil.createAndCopy(ProjectMember.class, memberDto);
        universalDao.insert(member);
    }
}
```

## 複雑な業務ロジック

### トランザクション境界
```java
public OrderDto processOrder(OrderDto orderDto) {
    // トランザクションはActionで開始される
    // Serviceメソッド全体が1トランザクション内で実行
    
    // 在庫チェック
    validateStock(orderDto);
    
    // 注文登録
    Order order = createOrder(orderDto);
    
    // 在庫更新
    updateStock(orderDto);
    
    // メール送信（非トランザクション処理は別途考慮）
    // sendOrderConfirmationMail(order);
    
    return BeanUtil.createAndCopy(OrderDto.class, order);
}

private void validateStock(OrderDto orderDto) {
    for (OrderItemDto itemDto : orderDto.getItems()) {
        Product product = universalDao.findById(Product.class, itemDto.getProductId());
        if (product.getStock() < itemDto.getQuantity()) {
            throw new InsufficientStockException(product.getProductName());
        }
    }
}

private Order createOrder(OrderDto orderDto) {
    Order order = BeanUtil.createAndCopy(Order.class, orderDto);
    order.setOrderDate(SystemTimeUtil.getTimestamp());
    universalDao.insert(order);
    return order;
}

private void updateStock(OrderDto orderDto) {
    for (OrderItemDto itemDto : orderDto.getItems()) {
        Product product = universalDao.findById(Product.class, itemDto.getProductId());
        product.setStock(product.getStock() - itemDto.getQuantity());
        universalDao.update(product);
    }
}
```

```java
public void validateProjectUpdate(ProjectDto projectDto) {
    // 顧客の存在チェック
    if (projectDto.getClientId() != null) {
        if (!universalDao.exists(Client.class, "FIND_BY_CLIENT_ID",
                new Object[]{projectDto.getClientId()})) {
            throw new ApplicationException(
                MessageUtil.createMessage(MessageLevel.ERROR,
                    "errors.nothing.client", projectDto.getClientId()));
        }
    }
    
    // プロジェクト期間の整合性チェック
    if (projectDto.getProjectEndDate().before(projectDto.getProjectStartDate())) {
        throw new ApplicationException(
            MessageUtil.createMessage(MessageLevel.ERROR,
                "errors.invalid.projectPeriod"));
    }
}
```

```java
public ProjectStatistics calculateStatistics(Long projectId) {

    stats.setSales(project.getSales());
    stats.setCost(project.getCostOfGoodsSold() + project.getSga());
```

## SQLファイルの使用

### 基本SQL
```sql
-- Project.sql
SEARCH_PROJECT =
SELECT
    PROJECT_ID,
    PROJECT_NAME,
    PROJECT_TYPE,
    PROJECT_CLASS,
    PROJECT_START_DATE,
    PROJECT_END_DATE,
    VERSION
FROM
    PROJECT
WHERE
    USER_ID = :userId
    AND $if(projectName) {PROJECT_NAME LIKE :%projectName%}
    AND $if(projectType) {PROJECT_TYPE = :projectType}
    AND $if(projectClass) {PROJECT_CLASS IN (:projectClass[])}
ORDER BY
    PROJECT_ID
```

### JOIN SQL
```sql
-- Project.sql
FIND_BY_PROJECT =
SELECT
    p.PROJECT_ID,
    p.PROJECT_NAME,
    p.PROJECT_TYPE,
    c.CLIENT_NAME,
    c.INDUSTRY_CODE
FROM
    PROJECT p
LEFT OUTER JOIN
    CLIENT c ON p.CLIENT_ID = c.CLIENT_ID
WHERE
    p.PROJECT_ID = ?
    AND p.USER_ID = ?
```

### Formクラスへの依存禁止

```java
    // ServiceがFormに依存してしまう
}

// ✅OK例

    // ServiceはEntityに依存
}
```

### DaoContextのインジェクション
```java
public class ProjectService {
    private final DaoContext universalDao;
    
    // 本番用（DaoFactory経由）
    public ProjectService() { 
        this(DaoFactory.create()); 
    }
    
    // テスト用（モックをインジェクション可能）
    ProjectService(DaoContext universalDao) { 
        this.universalDao = universalDao; 
    }

```

### トランザクション管理
- トランザクションはActionハンドラで自動管理
- Serviceメソッドは1トランザクション内で実行
- 例外発生時は自動ロールバック

### 楽観的ロック
- `version` カラムを使用
- `update()` 実行時に自動チェック
- バージョン不一致時は `OptimisticLockException` 発生

### エラーハンドリング
- ビジネスルール違反: `ApplicationException` をスロー
- データ不在: `NoDataException` （`findById`等で自動発生）
- 一意制約違反: 独自例外クラスを定義してスロー

### Serviceクラスの責務
- ビジネスロジックの実装
- データベースアクセス
- トランザクション内処理
- ビジネスルールのバリデーション
