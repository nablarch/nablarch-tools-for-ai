# 1.4 メッセージ管理

## 基本使用

### メッセージ定義（messages.properties）
```properties
# プレフィックスによる分類（label/errors/success/api/batch）
label.user.register.title=ユーザ登録画面
errors.login.alreadyExist=入力されたログインIDは既に登録されています。
success.upload.project={0}件のプロジェクトを登録しました。
user.welcome.message={userName}さん、こんにちは。最終ログイン：{lastLogin}

# バリデーション用（Bean Validation連携）
nablarch.core.validation.ee.Required.message=入力してください。
nablarch.core.validation.ee.Length.min.max.message={min}文字以上{max}文字以内で入力してください。
nablarch.core.validation.ee.SystemChar.message={charsetDef}を入力してください。
```

### プログラムでの使用
```java
// 基本的なメッセージ作成
Message message = MessageUtil.createMessage(MessageLevel.ERROR, "errors.login.alreadyExist");
throw new ApplicationException(message);

// パラメータ埋め込み（配列）
MessageUtil.createMessage(MessageLevel.INFO, "success.upload.project", projects.size());

// パラメータ埋め込み（Map）：キー名がプレースホルダーに対応
Map<String, Object> options = new HashMap<>();
options.put("userName", user.getName());
options.put("lastLogin", user.getLastLoginDate());
MessageUtil.createMessage(MessageLevel.INFO, "user.welcome.message", options);
```

## アプリケーション別実装例

### Web: Action → JSP
```java
// Action: メッセージ設定
context.setRequestScopedVar("message", 
    MessageUtil.createMessage(MessageLevel.INFO, "success.update.project").formatMessage());
```
```jsp
<!-- JSP: 表示 -->
<n:message messageId="label.user.register.title" />  <!-- 固定文言 -->
<div class="alert alert-success" role="alert">
  <n:write name="message" />                         <!-- メッセージ表示 -->
</div>
```

### Batch: ログ出力
```java
public class ProjectBatchAction extends BatchAction<ProjectForm> {
    @Override
    public Result handle(ProjectForm inputData, ExecutionContext ctx) {
        try {
            // 業務処理...
        } catch (ApplicationException e) {
            LOGGER.logWarn(MessageUtil.createMessage(MessageLevel.WARN, 
                "batch.warning.skip", inputData.getProjectId()).formatMessage());
        }
        return new Success();
    }
}
```
