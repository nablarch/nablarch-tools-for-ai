# 4.2 Form（入力値受け取り）

Webアプリケーションで受け取る値のパターン。基本バリデーションは1_common/1.3_validation.md参照。

## 基本原則

### フォームのプロパティ定義
- **全てString型で宣言** （日付、数値も含む）
- 理由: バリデーションエラー時に入力値を再表示するため

### フォームの単位
- HTMLのフォーム単位で作成
- 画面ごとに専用フォームを作成（入力項目が重複しても別フォーム）
- 理由: 責務の分離、画面固有のバリデーション対応

### Serializableの実装
- `@InjectForm` 使用時は `Serializable` を実装必須
- セッションストアへの格納時にも必要

## 検索フォーム

### 基本検索フォーム
```java
public class ProjectSearchForm implements Serializable {
    
    /** プロジェクト名 */
    @Domain("projectName")
    private String projectName;
    
    /** プロジェクト開始日（FROM） */
    @Domain("date")
    private String projectStartDateBegin;
    
    /** プロジェクト開始日（TO） */
    @Domain("date")
    private String projectStartDateEnd;
    
    /** プロジェクト種別（複数選択） */
    @Domain("projectType")
    private List<String> projectClass;
    
    /** ページ番号 */
    @Domain("pageNumber")
    private String pageNumber;
    
    // ゲッタ及びセッタは省略
}
```

### ページング用プロパティ
- ページ番号を保持する `pageNumber` プロパティを定義

### 複数選択プロパティ
- チェックボックス、複数選択プルダウンは `List<String>` で受け取る

## パスパラメータ受け取りフォーム

```java
public class ProjectTargetForm implements Serializable {
    
    /** プロジェクトID（パスパラメータ） */
    @Required
    @Domain("id")
    private String projectId;
    
    // ゲッタ及びセッタは省略
}
```

### routes.xmlとの対応
```xml
<!-- routes.xml -->
<get path="/action/project/show/:projectId" to="Project#show"/>
```
- `:projectId` がフォームの `projectId` プロパティにマッピング

## 登録フォーム

```java
public class ClientForm implements Serializable {
    
    /** 顧客名 */
    @Required
    @Domain("clientName")
    private String clientName;
    
    /** 業種コード */
    @Required(message = "{nablarch.core.validation.ee.Required.select.message}")
    @Domain("industryCode")
    private String industryCode;
    
    // ゲッタ及びセッタは省略
}
```

### プルダウン用のカスタムメッセージ
```properties
# messages.properties
nablarch.core.validation.ee.Required.select.message=選択してください。
```

### PartInfo
- `nablarch.fw.web.upload.PartInfo` を使用
- ファイル情報（ファイル名、サイズ、入力ストリーム）を保持

## 一括登録フォーム

```java
public class ProjectBulkForm implements Serializable {
    
    /** プロジェクトリスト */
    @Valid
    @Size(max = 100)
    private List<ProjectForm> projects;
    
    // ゲッタ及びセッタは省略
}

public class ProjectForm implements Serializable {
    
    @Required
    @Domain("projectName")
    private String projectName;
    
    @Required
    @Domain("projectType")
    private String projectType;
    
    // ゲッタ及びセッタは省略
}
```

### ネストしたバリデーション
- `@Valid` でネストしたオブジェクトもバリデーション
- `@Size` でリストのサイズ制限

## Actionでの使用方法

### GET（検索フォーム）
```java
@InjectForm(form = ProjectSearchForm.class, prefix = "searchForm", name = "searchForm")
@OnError(type = ApplicationException.class, path = "/WEB-INF/view/project/index.jsp")
public HttpResponse list(HttpRequest request, ExecutionContext context) {
    ProjectSearchForm searchForm = context.getRequestScopedVar("searchForm");
    // 処理実装
}
```

### POST（登録・更新フォーム）
```java
@InjectForm(form = ClientForm.class, prefix = "form")
@OnError(type = ApplicationException.class, path = "forward://input")
public HttpResponse confirm(HttpRequest request, ExecutionContext context) {
    ClientForm form = context.getRequestScopedVar("form");
    // 処理実装
}
```

### パスパラメータ
```java
@InjectForm(form = ProjectTargetForm.class)
public HttpResponse show(HttpRequest request, ExecutionContext context) {
    ProjectTargetForm targetForm = context.getRequestScopedVar("form");
    // 処理実装
}
```

## 重要ポイント

### プロパティの型
- **入力値受け取り**: 全てString型
- **変換先**: BeanUtilでDto/Entityに変換時に型変換

### フォームとDto/Entityの関係
- **フォーム**: プレゼンテーション層（画面からの入力値）
- **Dto**: データ転送用（検索条件、検索結果）
- **Entity**: データベースマッピング用

### バリデーション設定場所
- **Bean Validation**: フォームクラスにアノテーション
- **DB検索が必要**: Actionメソッド内で実装

### セッションストアへの格納
- **NG**: フォームを直接格納
- **OK**: エンティティに変換してから格納
```java
// NG例
SessionUtil.put(context, "client", form);

// OK例
Client client = BeanUtil.createAndCopy(Client.class, form);
SessionUtil.put(context, "client", client);
```

### 責務の分離
- フォームは画面固有の入力値受け取りに特化
- ビジネスロジックはServiceクラスで実装
- Actionはフォームとサービスの橋渡し
