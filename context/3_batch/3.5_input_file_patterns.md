# 3.5 ファイル入力パターン

## 基本実装

ObjectMapperのようにhasNextメソッドがない場合でも、イテレータを作成すればデータリーダの実装が簡単になり、バッチごとの個別実装が不要になる。イテレータの実装例は下記参照。

```java
public class FileDataReader implements DataReader<ImportForm> {
    private ObjectMapperIterator<ImportForm> iterator;
    public ImportForm read(ExecutionContext ctx) {
        if (iterator == null) initialize();
        return iterator.next();
    }
    public boolean hasNext(ExecutionContext ctx) {
        if (iterator == null) initialize();
        return iterator.hasNext();
    }
    public void close(ExecutionContext ctx) {
        if (iterator != null) iterator.close();
    }
    private void initialize() {
        File file = FilePathSetting.getInstance().getFileWithoutCreate("input", "fileName");
        iterator = new ObjectMapperIterator<>(ObjectMapperFactory.create(ImportForm.class, new FileInputStream(file)));
    }
}

public class FileImportAction extends BatchAction<ImportForm> {
    public DataReader<ImportForm> createReader(ExecutionContext context) {
        return new FileDataReader();
    }
    @ValidateData
    public Result handle(ImportForm inputData, ExecutionContext context) {
        processValidatedData(inputData);
        return new Success();
    }
}
```

## @ValidateData使用

> **重要:**  
> FormにDomainアノテーションを付与しただけではバリデーションは自動実行されない。  
> バリデーションを有効にするには、`@ValidateData`インターセプターを利用する必要がある。  
> `@ValidateData`をメソッドに付与することで、入力データのバリデーションが自動的に実行される。
> `@ValidateData`インターセプターはプロジェクトごとに要実装。

### Formクラス
```java
@Csv(properties = {"id", "name", "amount"}, type = CsvType.CUSTOM)
@CsvFormat(
        fieldSeparator = ',',
        lineSeparator = "\r\n",
        quote = '"',
        ignoreEmptyLine = false,
        requiredHeader = false,
        charset = "UTF-8",
        quoteMode = CsvDataBindConfig.QuoteMode.NORMAL,
        emptyToNull = true)
public class ImportForm {
    @Domain("userId") private String id;
    @Domain("userName") private String name;
    @Domain("amount") private String amount;
    private Long lineNumber; // エラー行特定用
    // getter/setter
}
```

### CSV形式
```java
@Csv(properties = {"id", "name", "amount"}, type = CsvType.CUSTOM)
```

### 固定長形式  
```java
@FixedLength(length = 100, charset = "UTF-8")
public class FixedImportForm {
    @Field(offset = 1, length = 10) @Domain("userId") private String id;
    @Field(offset = 11, length = 20) @Domain("userName") private String name;
    // getter/setter
}
```
