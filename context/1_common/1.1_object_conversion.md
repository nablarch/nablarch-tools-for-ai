# 1.1 Nablarchオブジェクト変換戦略

## 変換ツール選択ルール
| 変換元 | 変換先 | 使用ツール |
|-------|-------|----------|
| SqlRow | Entity/DTO | EntityUtil.createEntity() |
| Form | Entity/DTO | BeanUtil.createAndCopy() |
| Entity/DTO | Form | BeanUtil.createAndCopy() |
| Map | Entity/DTO | BeanUtil.createAndCopy() |

## EntityUtil概要（SqlRow専用）

### 基本的な使用方法
```java
// データベース検索結果をEntityに変換
UserEntity entity = EntityUtil.createEntity(UserEntity.class, sqlRow);

// Enumは手動設定が必要
entity.setStatus(UserStatus.valueOf(sqlRow.getString("status_code")));
```

### SqlRowのキー名判別機能
```java
// SqlRowは大文字・小文字・アンダースコアを区別しない
// 以下は全て同じカラムを参照する
sqlRow.getString("user_id");     // スネークケース（DB標準）
sqlRow.getString("USER_ID");     // 大文字
sqlRow.getString("userId");      // キャメルケース（Java標準）
sqlRow.getString("UserId");      // パスカルケース

// EntityUtilも同様に柔軟にマッピング
// DB列名 USER_ID → Javaプロパティ userId に自動変換
UserEntity entity = EntityUtil.createEntity(UserEntity.class, sqlRow);
```

### 実用例
```java
// バッチ処理でのSqlRow変換（DatabaseRecordReader使用時）
@Override
public Result handle(SqlRow inputData, ExecutionContext context) {
    // SqlRowからEntityに変換
    SourceEntity entity = EntityUtil.createEntity(SourceEntity.class, inputData);
    
    // Enumのみ個別設定
    entity.setStatus(ProcessStatus.valueOf(inputData.getString("STATUS_CODE")));
    
    // 業務処理実行
    processEntity(entity);
    return new Success();
}
```

## BeanUtil概要（Form/Map専用）

### 基本的な使用方法
```java
// Form → Entity変換
UserEntity entity = BeanUtil.createAndCopy(UserEntity.class, form);

// Entity → Form変換
UserForm form = BeanUtil.createAndCopy(UserForm.class, entity);

// Map → Entity変換
UserEntity entity = BeanUtil.createAndCopy(UserEntity.class, dataMap);
```

### 詳細仕様
BeanUtilの詳細仕様は「1.3_bean_util.md」を参照してください。

## 自動型変換範囲

### 両ツール共通対応型
- String, Integer, Long, Short, Boolean, BigDecimal
- Date, Timestamp, LocalDate, LocalDateTime

### BeanUtil追加対応
- 配列、List、ネストしたオブジェクト
- CopyOptionsによる詳細制御

### EntityUtil専用機能
- SqlRowのキー名柔軟判別（スネーク↔キャメル自動変換）
- データベース型からJava型への最適化変換

### 手動対応が必要な型
- Enum（valueOf()使用）
- 独自型・カスタム型

## 使用場面別パターン

### バッチ処理でのDatabaseRecordReader使用時
```java
// EntityUtil使用（バッチ処理のみ）
@Override
public DataReader<SqlRow> createReader(ExecutionContext context) {
    DatabaseRecordReader reader = new DatabaseRecordReader();
    SqlPStatement statement = getSqlPStatement("FIND_DATA_BY_STATUS");
    statement.setString(1, "ACTIVE");
    reader.setStatement(statement);
    return reader;
}

@Override
public Result handle(SqlRow inputData, ExecutionContext context) {
    // SqlRowからEntityに変換
    DataEntity entity = EntityUtil.createEntity(DataEntity.class, inputData);
    entity.setStatus(DataStatus.valueOf(inputData.getString("STATUS_CODE")));
    
    // 業務処理実行
    processData(entity);
    return new Success();
}
```

### 画面フォームとの変換
```java
// BeanUtil使用
@InjectForm(form = UserForm.class, name = "form")
public HttpResponse create(HttpRequest request, ExecutionContext context) {
    UserForm form = context.getRequestScopedVar("form");
    
    // Form → Entity変換
    UserEntity entity = BeanUtil.createAndCopy(UserEntity.class, form);
    
    UniversalDao.insert(entity);
    return new HttpResponse("redirect://complete");
}
```

### セッション管理での変換
```java
// BeanUtil使用
public HttpResponse input(HttpRequest request, ExecutionContext context) {
    // セッションからEntityを取得
    UserEntity user = SessionUtil.get(context, "user");
    
    // Entity → Form変換で画面表示用に設定
    UserForm form = BeanUtil.createAndCopy(UserForm.class, user);
    context.setRequestScopedVar("form", form);
    
    return new HttpResponse("/WEB-INF/view/user/input.jsp");
}
```

## 非効率パターン（避けるべき）
```java
// 全項目手動移送
UserEntity entity = new UserEntity();
entity.setUserId(sqlRow.getString("user_id"));
entity.setBirthDate(DateUtil.parseDate(sqlRow.getString("birth_date"), "yyyy-MM-dd")); // 不要
```

## AIコード生成指針
1. **変換元・変換先に応じて適切なツールを選択**
   - SqlRow → Entity/DTO: EntityUtil.createEntity()
   - Form ↔ Entity/DTO: BeanUtil.createAndCopy()
   - Map ↔ Entity/DTO: BeanUtil.createAndCopy()

2. **ユーティリティで大部分の項目と型変換を自動処理**
   - 基本型変換は手動実装禁止
   - SqlRowではキー名の記法（スネーク・キャメル等）を気にしない

3. **Enum・独自型のみ個別setter実装**
   - entity.setStatus(UserStatus.valueOf(sqlRow.getString("status_code")));

4. **EntityUtilはcreateEntity()のみ使用**
   - その他のメソッド（findAllColumns等）は使用しない
