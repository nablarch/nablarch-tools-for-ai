# 段階的実装ガイド（バッチ）

## 実装順序と必要ファイル

### 段階1: Form・DTO・Entity定義
**読み込みファイル**: `3.1_form_dto_basics.md` のみ

- 入力Form（CSV/固定長）の定義
- 出力DTOの定義  
- Entityの定義
- 基本ユーティリティの使い方

### 段階2: DataReader実装
**読み込みファイル**: `3.2_reader_patterns.md` のみ

- ファイル読み込みReaderの実装
- DB読み込みReaderの実装
- 必須メソッドとリソース解放

### 段階3: BatchAction実装
**読み込みファイル**: `3.3_action_patterns.md` のみ

- 基本的なBatchActionの構造
- パターン別実装（ファイル→DB、DB→ファイル、DB→DB）
- エラーハンドリング
- 禁止パターン

## 特定パターンの詳細実装

### 段階4: 特定パターンの実装（必要に応じて）
各パターンの詳細が必要な場合のみ追加で読み込み：

- **DBからファイル出力**: `3.4_db_to_file_pattern.md`
- **ファイルからDB登録**: `3.5_file_to_db_pattern.md`  
- **DBからDB処理**: `3.6_db_to_db_pattern.md`
- **ファイル変換**: `3.7_file_to_file_pattern.md`
- **エラーハンドリング**: `3.8_error_handling_pattern.md`
- **悲観ロック**: `3.9_pessimistic_lock_pattern.md`

## 最小構成

### 基本的なバッチ処理
1. `3.1_form_dto_basics.md`
2. `3.2_reader_patterns.md`  
3. `3.3_action_patterns.md`

**合計3ファイル**で基本的なバッチ処理を実装可能

### 特定パターンの詳細実装
基本3ファイル + 必要なパターンファイル1つ

**合計4ファイル**で特定パターンの詳細実装が可能
