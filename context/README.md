# Nablarch AI Context Documentation

## 概要

このフォルダは、AIがNablarchアプリケーションを実装する際に、コンテキストとして注入するための情報を格納しています。  
Nablarchの仕様の中から、特に実装時に参照が必須となる重要な情報をMarkdown形式で抽出・整理しています。

## 目的

AIによるコード生成やレビューの精度を向上させるためには、Nablarchフレームワークの核心的な仕様や規約をコンテキストとして提供することが不可欠です。  
このフォルダ内のドキュメントは、そのための情報源となります。

## ディレクトリ構成

仕様に関するドキュメントは、Nablarchがサポートする代表的な処理方式に基づいて格納されています。

### 1_common - 共通機能
アプリケーションの処理方式を問わず利用される共通的な機能の仕様

#### 基盤機能（データ変換・検証）
- **1.1 オブジェクト変換戦略** - EntityUtil/BeanUtil概要、使い分け指針、キー名変換
- **1.2 BeanUtil詳細ガイド** - Form↔Entity変換、Map変換、型変換ルール
- **1.3 入力値検証** - Bean Validation、ドメインバリデーション、相関バリデーション

#### データアクセス・永続化
- **1.4 データベースアクセス** - UniversalDAO、JDBCラッパー、SQLファイル管理

#### 入出力・ファイル処理
- **1.5 データバインド** - CSV/固定長ファイル変換、アップロード/ダウンロード
- **1.6 ファイルパス管理** - 論理名管理、環境別設定、パス操作

#### ユーティリティ・共通機能
- **1.7 日付・時刻ユーティリティ** - BusinessDateUtil、DateUtil、業務日付変換
- **1.8 メッセージ管理** - メッセージ定義、国際化対応、エラーメッセージ

### 2_rest - RESTful Webサービス
RESTful Webサービス固有の仕様
- **2.1 Action（リソースクラス）** - JAX-RSアノテーション、レスポンス制御
- **2.2 Form（REST特有）** - パラメータ受信、バリデーション、JSON変換
- **2.3 レスポンス・エラーハンドリング** - ステータスコード制御、例外処理
- **2.4 Service** - 依存関係管理、テスト対応、ビジネスロジック分離

### 3_batch - バッチ処理
バッチ処理固有の仕様
- **3.1 Form・DTO定義** - CSV/固定長Form、出力DTO、バリデーション指針
- **3.2 DataReader** - DatabaseRecordReader、FileDataReader、カスタムReader
- **3.3 BatchAction** - エラーハンドリング、初期化・終了処理、1レコード処理
- **3.4 データベース入力パターン** - SQL実行パターン、大量データ処理
- **3.5 ファイル入力パターン** - CSV/固定長読込み、エラー制御
- **3.6 DB出力パターン** - バッチ更新、トランザクション制御
- **3.7 ファイル出力パターン** - CSV/固定長出力、フォーマット制御
- **3.8 @ValidateData** - バリデーション制御アノテーション

### 4_web - ウェブアプリケーション
ウェブアプリケーション固有の仕様
- **4.1 ファイルアップロード・ダウンロード** - ファイル操作、CSV生成、Excel出力
- **4.2 Web画面遷移パターン** - 入力・確認・実行画面、セッション管理、JSP表示
