# 1.3 入力値検証

## ドメインバリデーション
```java
// ドメインBean定義
public class SampleDomainBean {
    @Length(max = 50) @SystemChar(charsetDef = "全角文字") String name;
    @Length(min = 8, max = 8) @SystemChar(charsetDef = "半角数字") String date;
    @NumberRange(min = 0, max = 999) Integer code;
}

// Form使用
public class UserForm {
    @Domain("name") @Required private String userName;  // 必須は個別設定
    @Domain("date") private String birthday;
    @Domain("code") private String userCode;
}
```

## 主要アノテーション
- `@Required`: 必須
- `@Length(min=?,max=?)`: 文字列長
- `@SystemChar(charsetDef="文字種名")`: 文字種
- `@Domain("ドメイン名")`: ドメイン適用
- `@NumberRange(min=?,max=?)`: 数値範囲(整数)
- `@DecimalRange(min="?",max="?")`: 数値範囲(小数)

## 実行パターン
```java
// Web自動実行
@InjectForm(form = UserForm.class, name = "form")
public HttpResponse create(HttpRequest request, ExecutionContext context) {
    UserForm form = context.getRequestScopedVar("form"); // バリデーション済み
}

// REST自動実行
@POST @Valid @Consumes(MediaType.APPLICATION_JSON)
public ResponseDto create(UserForm form) { // バリデーション済み }

// 明示実行
ValidatorUtil.validate(form);
ValidatorUtil.validateWithGroup(form, ValidationGroup.Create.class);
```

## 相関バリデーション
```java
public class UserForm {
    @Domain("password") @Required private String password;
    @Domain("password") @Required private String confirmPassword;

    @AssertTrue(message = "{passwordMatch}")
    public boolean isPasswordMatch() {
        if (StringUtil.isNullOrEmpty(password) || StringUtil.isNullOrEmpty(confirmPassword)) {
            return true; // 単項目バリデーションに委ねる
        }
        return Objects.equals(password, confirmPassword);
    }
}
```

## リスト/ネストバリデーション
```java
public class BulkUserForm {
    @Valid @Size(min = 1, max = 10) private List<UserForm> users;
    public BulkUserForm() { users = new ArrayList<>(); }
}
```

## メッセージ例
```properties
nablarch.core.validation.ee.Required.message=入力してください。
nablarch.core.validation.ee.Length.min.max.message={min}文字以上{max}文字以内で入力してください。
sample.UserForm.userName=ユーザー名
```

## 制約
- **プロパティ全てString型**: 型変換エラー防止
- **@Required個別設定**: ドメインでは設定しない  
- **相関バリデーション**: null/空文字考慮必要
