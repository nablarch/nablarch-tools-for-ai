# 1.4 DBアクセス

## 基本方針
**UniversalDAO推奨**、JDBCラッパーは特定条件のみ（バッチDatabaseRecordReader、特殊SQL）

## CRUD基本
```java
// Entity
@Entity @Table(name = "USERS") public class User {
    @Id @Column(name = "USER_ID") private Long userId;
    @Column(name = "USER_NAME") private String userName;
}

// 操作
UniversalDao.insert(user);                    // 登録（バージョン番号自動設定）
UniversalDao.findById(User.class, id);        // 検索(例外)
UniversalDao.findByIdOrNull(User.class, id);  // 検索(null)
UniversalDao.update(user); delete(user);

// insert後自動採番取得（insertは採番値返さない）
universalDao.insert(user);
User saved = universalDao.findBySqlFile(User.class, "FIND_BY_EMAIL", user); // ユニーク項目で再取得
```

## 可変条件SQL
```sql
SEARCH_USERS =
SELECT USER_ID, USER_NAME FROM USERS
WHERE $if (userName) {USER_NAME LIKE :userName%}
  AND $if (email) {EMAIL = :email}
ORDER BY USER_ID
```
**ルール**: `$if(property) {条件}`、入力なし→`(0=0 or 条件)`、入力あり→`(0=1 or 条件)`、AND/OR接続詞の条件分岐不要

## 動的SQL構文
- `$if(property) {条件}`: 可変条件
- `:propertyName`: パラメータ 
- `:userName%`: LIKE前方一致
- `(:userTypes[])`: IN句
- `$sort(sortId) { (id_asc ID ASC) (default ID) }`: ORDER BY

## 高度機能
```java
UniversalDao.batchInsert(users); batchUpdate(users); batchDelete(users); // バッチ
EntityList<User> users = UniversalDao.per(10).page(1).findAllBySqlFile(...); // ページング
try (DeferredEntityList<User> users = UniversalDao.defer().findAllBySqlFile(...)) { // 遅延ロード
    for (User user : users) { /* 1件ずつ処理 */ }
}
```

## テスト対応Service
```java
public class UserService {
    private final DaoContext universalDao;
    public UserService() { this(DaoFactory.create()); } // DaoFactoryは各自実装が必要
    UserService(DaoContext universalDao) { this.universalDao = universalDao; }
    public User findById(Long id) { return universalDao.findById(User.class, id); }
}
```

## JDBCラッパー（特定用途のみ）

> **重要：**  
> JDBCラッパーは以下の場合にのみ使用してください。UniversalDAOで対応できる場合は使用しないこと。
> - UniversalDAOで対応できない機能（スキーマ置換、特殊なSQL）
> - バッチ処理のDatabaseRecordReaderでの読み取り
> - パフォーマンス要件などで特別な制御が必要

**バッチDatabaseRecordReader**
```java
@Override
public DataReader<SqlRow> createReader(ExecutionContext context) {
    DatabaseRecordReader reader = new DatabaseRecordReader();
    SqlPStatement statement = getSqlPStatement("FIND_DATA");
    statement.setString(1, "ACTIVE");
    reader.setStatement(statement);
    return reader;
}
```
**SQLファイル配置**: `com.example.batch.UserBatchAction` → `com/example/batch/UserBatchAction.sql`
