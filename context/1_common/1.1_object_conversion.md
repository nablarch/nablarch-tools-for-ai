# 1.1 Nablarchオブジェクト変換

## 変換ツール選択
| 変換元 | 変換先 | ツール |
|-------|-------|-------|
| SqlRow | Entity/DTO | EntityUtil.createEntity() |
| Form/Map | Entity/DTO | BeanUtil.createAndCopy() |

## EntityUtil（SqlRow専用）
```java
// 基本変換
UserEntity entity = EntityUtil.createEntity(UserEntity.class, sqlRow);
entity.setStatus(UserStatus.valueOf(sqlRow.getString("status_code"))); // Enum手動設定
```

**SqlRowキー名判別**: SqlRowは大文字・小文字・アンダースコアを区別しない。user_id/USER_ID/userId/UserId全て同一判定

## BeanUtil（Form/Map専用）
```java
// Form ↔ Entity
UserEntity entity = BeanUtil.createAndCopy(UserEntity.class, form);
UserForm form = BeanUtil.createAndCopy(UserForm.class, entity);

```

## 自動型変換
**対応型**: String,Integer,Long,Short,Boolean,BigDecimal,Date,Timestamp,LocalDate,LocalDateTime
**手動対応**: Enum(valueOf使用),独自型

## 指針
1. SqlRow→EntityはEntityUtil.createEntity()
2. Form/Map変換はBeanUtil.createAndCopy()
3. 基本型は自動変換、Enumのみ手動設定
4. 手動項目移送禁止
