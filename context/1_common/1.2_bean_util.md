# 1.2 BeanUtil詳細パターン

## 主要メソッド
```java
UserDto dto = BeanUtil.createAndCopy(UserDto.class, form);           // 新規作成+コピー
BeanUtil.copy(form, entity);                                         // 既存へコピー
String name = (String) BeanUtil.getProperty(user, "name");           // プロパティ取得
BeanUtil.setProperty(user, "name", "新しい名前");                     // プロパティ設定
Map<String, Object> map = BeanUtil.createMapAndCopy(user);           // Map変換
```

## 特殊パターン

### 上書きコピー
```java
// セッションから元Entity取得→Form値で上書き
User user = SessionUtil.get(context, "user");
BeanUtil.copy(form, user);
UniversalDao.update(user);
```

### ネストオブジェクト
```java
// Mapでドット記法ネスト指定
Map<String, Object> data = new HashMap<>();
data.put("address.postNo", "123-4567");
data.put("address.prefecture", "東京都");
User user = BeanUtil.createAndCopy(User.class, data);
```

### 型変換制御
```java
// CopyOptionsで日付フォーマット指定
CopyOptions options = CopyOptions.options()
    .datePatternByName("birthday", "yyyy/MM/dd")
    .build();
UserForm form = BeanUtil.createAndCopy(UserForm.class, data, options);
```

### 検索条件変換
```java
// SearchForm → SearchDto
ProjectSearchDto searchDto = BeanUtil.createAndCopy(ProjectSearchDto.class, searchForm);
EntityList<Project> projects = UniversalDao.findAllBySqlFile(Project.class, "SEARCH_PROJECT", searchDto);
```

### REST JSON変換  
```java
@POST @Consumes(MediaType.APPLICATION_JSON) @Valid
public HttpResponse create(UserCreateForm form) {
    User user = BeanUtil.createAndCopy(User.class, form);
    UniversalDao.insert(user);
    return new HttpResponse(HttpResponse.Status.CREATED.getStatusCode());
}

@GET @Path("/{userId}") @Produces(MediaType.APPLICATION_JSON)
public UserDto findById(JaxRsHttpRequest request) {
    User user = UniversalDao.findById(User.class, request.getPathParam("userId"));
    return BeanUtil.createAndCopy(UserDto.class, user);
}
```

### バッチファイル変換
```java
// CSVForm → Entity
try (ObjectMapper<UserCsvForm> mapper = ObjectMapperFactory.create(UserCsvForm.class, inputStream)) {
    UserCsvForm csvForm;
    while ((csvForm = mapper.read()) != null) {
        User user = BeanUtil.createAndCopy(User.class, csvForm);
        UniversalDao.insert(user);
    }
}
```

### List型パラメータ対応
```java
// ジェネリクス基底クラス
public class ItemsForm<D extends Serializable> {
    private List<D> items;
    public List<D> getItems() { return items; }
    public void setItems(List<D> items) { this.items = items; }
}

public class Item implements Serializable {
    private String name;
    // getter/setter省略
}

// ❌ NG: 具象クラスでオーバーライドしない
// BeanUtil.createAndCopy(BadForm.class, map)で実行時例外発生
public class BadForm extends ItemsForm<Item> {
}

// ✅ OK: 具象クラスでgetterをオーバーライド
public class GoodForm extends ItemsForm<Item> {
    @Override
    public List<Item> getItems() {
        return super.getItems();
    }
}
```

## 制約
- **SqlRow変換不可**（EntityUtil使用）
- **同名プロパティのみコピー**
- **List型パラメータ非対応**（具象クラスでgetterオーバーライド必須）
- **型変換精度注意**（Long→Integer等）
