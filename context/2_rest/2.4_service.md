# 2.4 Service

## 実装方針

DaoContextでDBアクセス。テスト時スタブ差し替え可能。

> **重要：Serviceクラスの依存関係**
> 
> ServiceクラスではFormクラスに依存してはいけません：
> - **❌NG**: `UserForm`、`UserSearchForm`などのFormクラスを引数に取る
> - **✅OK**: `Entity`クラス、`Dto`クラス、プリミティブ型を引数に取る
> 
> **理由**: 
> - Formはプレゼンテーション層の関心事
> - Serviceは純粋なビジネスロジック層として独立性を保つ
> - Formの変更がServiceに影響しないようにする

- **DaoContext**: UniversalDao内部クラス（スタティック利用のため差し替え困難）

## 基本CRUD
```java
public class UserService {
    private final DaoContext universalDao;
    public UserService() { this(DaoFactory.create()); }
    UserService(DaoContext universalDao) { this.universalDao = universalDao; }
    
    public List<User> findUsers(UserSearchDto condition) {
        // ★引数はDtoクラスを使用（UserSearchFormは使わない）
        return universalDao.findAllBySqlFile(User.class, "FIND_USERS", condition);
    }
    
    public User findById(Long userId) {
        // ★プリミティブ型の引数
        return universalDao.findById(User.class, userId);
    }
    
    public User create(User user) {
        // ★引数はEntityクラスを使用（UserFormは使わない）
        validateUserUniqueness(user.getEmail());
        user.setCreatedDate(SystemTimeUtil.getTimestamp());
        universalDao.insert(user);
        return universalDao.findBySqlFile(User.class, "FIND_USER_BY_EMAIL", user);
    }
    
    public User update(UserDto userDto) {
        // ★引数はDtoクラスを使用（UserFormは使わない）
        User user = universalDao.findById(User.class, userDto.getUserId());
        BeanUtil.copy(userDto, user, CopyOptions.options().excludesNull().build());
        user.setUpdatedDate(SystemTimeUtil.getTimestamp());
        universalDao.update(user);
        return user;
    }
    
    public void delete(Long userId) {
        User user = new User();
        user.setUserId(userId);
        universalDao.delete(user);
    }
    
    private void validateUserUniqueness(String email) {
        User condition = new User();
        condition.setEmail(email);
        if (universalDao.countBySqlFile(User.class, "FIND_USER_BY_EMAIL", condition) > 0) {
            throw new DuplicateUserException(email);
        }
    }
}
```

## 複雑な業務ロジック
```java
public class OrderService {
    private final DaoContext universalDao;
    public OrderService() { this(DaoFactory.create()); }
    OrderService(DaoContext universalDao) { this.universalDao = universalDao; }
    
    public OrderDto createOrder(OrderDto orderDto) {
        Order order = BeanUtil.createAndCopy(Order.class, orderDto);
        universalDao.insert(order);
        
        for (OrderItemDto itemDto : orderDto.getItems()) {
            processOrderItem(order.getOrderId(), itemDto);
        }
        
        return universalDao.findBySqlFile(OrderDto.class, "FIND_ORDER_WITH_ITEMS", order);
    }
    
    private void processOrderItem(Long orderId, OrderItemDto itemDto) {
        Product product = universalDao.findById(Product.class, itemDto.getProductId());
        if (product.getStock() < itemDto.getQuantity()) {
            throw new InsufficientStockException(product.getProductName());
        }
        
        product.setStock(product.getStock() - itemDto.getQuantity());
        universalDao.update(product);
        
        OrderItem item = new OrderItem();
        item.setOrderId(orderId);
        item.setProductId(product.getProductId());
        item.setQuantity(itemDto.getQuantity());
        universalDao.insert(item);
    }
}
```

## 実装パターン

### ✅ 正しい実装パターン
```java
public class UserService {
    // ○ Entityクラスを引数に取る
    public User create(User user) { ... }
    
    // ○ Dtoクラスを引数に取る  
    public List<User> findUsers(UserSearchDto condition) { ... }
    
    // ○ プリミティブ型を引数に取る
    public User findById(Long userId) { ... }
    
    // ○ 複数のプリミティブ型を引数に取る
    public void updateStatus(Long userId, String status) { ... }
}
```

### ❌ 避けるべき実装パターン
```java
public class UserService {
    // ✗ Formクラスを引数に取るのはNG
    public User create(UserForm form) { ... }
    
    // ✗ SearchFormクラスを引数に取るのはNG
    public List<User> findUsers(UserSearchForm form) { ... }
    
    // ✗ GetFormクラスを引数に取るのはNG
    public User findById(UserGetForm form) { ... }
}
```

## テスト実装
```java
public class UserServiceTest {
    private UserService sut;
    
    @Test
    public void testFindById() {
        sut = new UserService(new DaoStub() {
            @Override
            public <T> T findById(Class<T> entityClass, Object... id) {
                User user = new User();
                user.setUserName("テストユーザー");
                return (T) user;
            }
        });
        
        User user = sut.findById(1L);
        assertThat(user.getUserName(), is("テストユーザー"));
    }
}
```
